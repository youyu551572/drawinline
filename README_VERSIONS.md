# 🎨 YouYu自动绘画 - 版本选择指南

## 📌 两个版本

本项目提供**两个版本**，功能完全相同，仅界面不同，您可以根据喜好选择：

---

## 🖼️ 版本对比

| 特性 | tkinter版（v1.0.32） | PyQt5版（v2.0.0） |
|------|---------------------|-------------------|
| **界面风格** | 传统Windows风格 | Material Design现代风格 |
| **外观评分** | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| **动画效果** | 无 | 有（200ms平滑） |
| **配色** | 系统默认 | 蓝色主题 + 彩色状态 |
| **窗口大小** | 900×650 | 1200×800 |
| **依赖安装** | ✅ 无需安装（Python内置） | ❌ 需要安装PyQt5 |
| **启动速度** | 快 | 稍慢（加载PyQt5） |
| **文件大小** | 小 | 较大（PyQt5库） |
| **跨平台** | ✅ Windows/Mac/Linux | ✅ Windows/Mac/Linux |
| **推荐场景** | 快速使用、资源受限 | 追求美观、体验优先 |

---

## 🚀 快速启动

### 1️⃣ tkinter版（v1.0.32）- 传统版

**优点**：
- ✅ 无需安装额外依赖
- ✅ 轻量级，启动快
- ✅ 稳定可靠

**启动方式**：
```bash
# 直接运行
python main.py

# 或双击
main.py
```

**界面特点**：
- 紧凑可爱（900×650）
- 可折叠面板
- Emoji图标
- 粉色主题点缀

---

### 2️⃣ PyQt5版（v2.0.0）- 现代版 ⭐**推荐**⭐

**优点**：
- ✅ 超级美观的现代化界面
- ✅ 流畅的动画效果
- ✅ 丰富的视觉反馈
- ✅ 更好的用户体验

**安装依赖**：
```bash
# 一键安装所有依赖
pip install -r requirements_pyqt.txt

# 或单独安装PyQt5
pip install PyQt5
```

**启动方式**：
```bash
# 运行PyQt5版本
python modern_main.py

# 或双击
modern_main.py
```

**界面特点**：
- Material Design风格
- 蓝色主题（#2196F3）
- 圆角组件（6px）
- 彩色状态提示
- 平滑动画过渡

## 📁 文件说明


```
imgprocess.py         # 图像处理逻辑（两个版本共享）

```

## ❓ 常见问题

### Q: 两个版本功能有区别吗？
**A**: 没有！功能完全相同，只是界面不同。

### Q: PyQt5版需要什么依赖？
**A**: 只需要PyQt5，运行以下命令即可：
```bash
pip install PyQt5
```

### Q: 可以同时安装两个版本吗？
**A**: 可以！它们互不干扰，想用哪个就用哪个。

### Q: PyQt5版为什么启动慢？
**A**: 因为需要加载PyQt5库，首次启动会慢一些，但界面加载完成后非常流畅。

### Q: 我应该选哪个版本？
**A**: 
- **新手/快速使用**：选tkinter版
- **追求体验**：选PyQt5版（强烈推荐！）
