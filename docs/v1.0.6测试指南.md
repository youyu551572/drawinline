# v1.0.6 测试指南

## 🎯 本次更新重点

v1.0.6 主要修复了两个关键问题：
1. **预览位置与实际绘画位置不一致**
2. **双线条问题改进**

---

## 测试1：位置一致性验证 ✅

### 问题背景
**旧版本现象**：
```
框选时预览：      实际绘画：
┌─────┐          ┌──────────┐
│ 图案 │    VS    │          │
└─────┘          │    图案  │
                 └──────────┘
```
位置和大小都不一致！

### 测试步骤

#### 步骤1：准备测试图片
```
选择一张简单的图片：
- 推荐：简笔画、Logo、几何图形
- 尺寸：建议800×600左右
```

#### 步骤2：处理图片
```
1. 运行程序：python main.py
2. 选择图片
3. 点击 🟡 中等模式（或保持默认）
4. 点击"处理图片"
5. 确认右侧预览显示正常
```

#### 步骤3：框选区域
```
1. 打开一个绘画程序（如画图、Photoshop等）
2. 点击"框选绘画区域"
3. 主窗口自动最小化
4. 拖动鼠标框选一个区域
5. 注意观察：
   ✓ 绿色预览线条的位置
   ✓ 线条的大小和形状
6. 按Enter确认
```

#### 步骤4：测试绘画
```
1. 在绘画程序中准备好画布
2. 回到主程序，点击"开始绘画"
3. 确认位置和倒计时
4. 等待绘画完成
```

#### 步骤5：对比验证
```
对比框选预览和实际绘画：

✅ 正确结果：
   - 位置完全一致
   - 大小完全一致
   - 形状完全一致

❌ 如果不一致：
   - 检查是否使用v1.0.6
   - 目标程序是否移动了
   - 尝试重新框选
```

### 关键检查点

| 项目 | 预览 | 实际 | 一致性 |
|------|------|------|--------|
| 左上角X坐标 | 记录 | 记录 | ✓/✗ |
| 左上角Y坐标 | 记录 | 记录 | ✓/✗ |
| 宽度 | 记录 | 记录 | ✓/✗ |
| 高度 | 记录 | 记录 | ✓/✗ |

**预期结果**：全部 ✓

## 测试2：双线条问题验证 🎯

### 问题背景
**双线条现象**：
```
单线边缘：    双线边缘：
    |             ||
    |      VS     ||
    |             ||
```

### 测试步骤

#### 步骤1：选择测试图片
```
选择容易产生双线条的图片：
- 矩形框
- 圆形
- 文字轮廓
- 线条图
```

#### 步骤2：处理并观察
```
1. 使用默认参数处理图片
2. 查看右侧预览
3. 仔细观察边缘：
   - 是否有平行的双线？
   - 线条是否清晰？
   - 是否有多余的线条？
```

#### 步骤3：对比不同模式

**简单模式测试**：
```
1. 点击 🟢 简单模式
2. 重新处理图片
3. 观察双线条情况
4. 记录：双线条比例 ____%
```

**中等模式测试**：
```
1. 点击 🟡 中等模式
2. 重新处理图片
3. 观察双线条情况
4. 记录：双线条比例 ____%
```

**复杂模式测试**：
```
1. 点击 🔴 复杂模式
2. 重新处理图片
3. 观察双线条情况
4. 记录：双线条比例 ____%
```

### 评估标准

**优秀（90%+单线条）**：
- ✓ 绝大部分边缘都是单线
- ✓ 只有极少数位置有轻微双线
- ✓ 整体效果清晰

**良好（80%+单线条）**：
- ✓ 大部分边缘是单线
- ✓ 少数位置有明显双线
- ✓ 整体可接受

**一般（60%+单线条）**：
- ✓ 约一半边缘是单线
- ✓ 较多位置有双线
- ✓ 需要调整参数

**较差（<60%单线条）**：
- ✗ 大量双线条
- ✗ 效果不理想
- ✗ 需要检查版本或参数

**v1.0.6预期**：80%+单线条（良好以上）
