# 新功能说明 - v1.0.3

## 概述

v1.0.3 版本引入了两项重要的用户体验改进：
1. **实时预览线条** - 在选择区域时即时看到绘画效果
2. **空格键暂停** - 更便捷的暂停控制方式

---

## 功能 1：实时预览线条

### 问题背景

**旧版本的问题**：
- 框选区域时看不到线条
- 不知道线条在区域内的实际位置
- 容易出现位置偏差
- 需要反复调整

**用户痛点**：
```
用户: "我框选了一个区域，但不知道图片会画在哪里..."
用户: "绘画后发现位置不对，需要重新来过..."
用户: "希望能提前看到绘画效果..."
```

### 解决方案

**实时预览系统**：
- ✅ 拖拽时立即显示绿色预览线条
- ✅ 线条随方框大小实时缩放
- ✅ 保持原图比例自动形变
- ✅ 所见即所得，零偏差

### 使用方法

#### 步骤 1：处理图片

首先必须处理图片生成线条数据：

1. 选择图片文件
2. 调整识别参数
3. 点击"处理图片"按钮
4. 等待处理完成

> ⚠️ **重要**：如果没有先处理图片，选择器中不会显示预览线条

#### 步骤 2：打开选择器

点击"📍 框选绘画区域"按钮

#### 步骤 3：观察预览

拖拽鼠标时：
- **红色方框**：选择的区域边界
- **绿色线条**：实际绘画的线条预览
- **黄色信息**：位置、尺寸、线条数量

#### 步骤 4：调整区域

根据预览效果调整：
- 如果线条太小 → 扩大方框
- 如果线条太大 → 缩小方框
- 如果位置不对 → 移动方框
- 如果比例不对 → 调整方框宽高比

#### 步骤 5：确认选择

按 Enter 确认，位置和尺寸完全一致！

### 技术细节

#### 缩放算法

```python
# 计算缩放比例
scale_x = 选择宽度 / 原图宽度
scale_y = 选择高度 / 原图高度

# 转换坐标
新X = 选择区域X + 原始点X * scale_x
新Y = 选择区域Y + 原始点Y * scale_y
```

#### 性能优化

- 只在区域 > 50x50 像素时绘制预览
- 使用 Canvas 标签快速删除和重绘
- 线条数量无上限，流畅绘制

#### 颜色选择

- **绿色 (#00FF00)**：高对比度，易于识别
- 半透明黑色背景：便于看清底层窗口
- 红色方框：明确标识选择区域

### 使用技巧

#### 技巧 1：先大后小

1. 先拖一个大致的区域
2. 观察预览线条
3. 再精确调整边界

#### 技巧 2：保持比例

如果原图是 800×600（4:3）：
- 框选时也保持 4:3 比例
- 例如：400×300、800×600、1600×1200
- 避免线条变形

#### 技巧 3：留出边距

- 方框稍大于预览线条
- 上下左右各留 10-20 像素
- 确保线条不会被裁剪

#### 技巧 4：对齐参考

如果目标程序有网格或标尺：
- 透过半透明窗口可以看到
- 用于精确对齐

### 常见问题

**Q: 为什么看不到绿色预览线条？**

A: 检查以下几点：
1. 是否先处理了图片？
2. 处理后是否有线条数据？
3. 方框是否足够大（>50x50）？

**Q: 预览线条和实际绘画会有偏差吗？**

A: 不会！预览使用的是完全相同的缩放算法，位置完全一致。

**Q: 预览线条太密集看不清？**

A: 可以：
1. 扩大选择区域
2. 或在处理图片时增大"简化程度"

**Q: 可以更改预览线条颜色吗？**

A: 当前版本固定为绿色。未来版本可能支持自定义。

## 功能 2：空格键暂停

### 问题背景

**旧版本的局限**：
- 只能点击按钮暂停
- 需要切换到程序窗口
- 操作不便
- 影响流程

**用户痛点**：
```
用户: "绘画时发现问题，想暂停但够不到按钮..."
用户: "每次暂停都要切窗口，太麻烦了..."
用户: "能不能用键盘快捷键？"
```

### 解决方案

**全局键盘监听**：
- ✅ 任何时候按空格键即可暂停
- ✅ 无需切换窗口
- ✅ 再按一次继续
- ✅ 自动同步GUI状态

### 使用方法

#### 前置条件

确保已安装 `pynput` 库：

```bash
pip install pynput
```

> 📌 **注意**：如未安装，程序会显示提示但仍可正常使用其他功能

#### 使用流程

1. **开始绘画**
   - 点击"开始绘画"按钮
   - 程序倒计时后开始

2. **观察状态栏**
   ```
   正在绘画: 5/25 (20.0%) [空格键暂停]
   ```

3. **按空格键暂停**
   - 直接按空格键
   - 鼠标立即停止
   - 状态变为：
   ```
   正在绘画: 5/25 (20.0%) [已暂停 - 按空格继续]
   ```

4. **再按空格继续**
   - 再次按空格键
   - 继续绘画
   - 状态恢复正常

#### 其他控制方式

空格键暂停与按钮暂停完全同步：

| 操作 | 效果 |
|------|------|
| 按空格 | 暂停 |
| 点按钮 | 暂停 |
| 再按空格 | 继续 |
| 再点按钮 | 继续 |

### 技术实现

#### 架构设计

```
┌─────────────────┐
│  pynput库       │  监听全局键盘
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ keyboard.Listener│  后台线程
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ _on_key_press() │  按键回调
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ space_pressed   │  标志变量
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ pause_callback()│  检查暂停
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 切换is_paused   │  暂停状态
└─────────────────┘
```

#### 代码流程

```python
# 1. 启动监听
keyboard_listener = keyboard.Listener(on_press=_on_key_press)
keyboard_listener.start()

# 2. 检测按键
def _on_key_press(key):
    if key == keyboard.Key.space:
        space_pressed = True

# 3. 绘画循环检查
def pause_callback():
    if space_pressed:
        space_pressed = False
        is_paused = not is_paused  # 切换状态
    return is_paused

# 4. 停止监听
keyboard_listener.stop()
```

#### 线程安全

- 使用标志变量传递状态
- 避免直接操作GUI
- 通过 `root.after()` 更新界面

### 使用技巧

#### 技巧 1：快速响应

空格键响应时间 < 0.1 秒：
- 检查频率很高
- 几乎即时暂停

#### 技巧 2：紧急情况

如果程序失去响应：
1. 先尝试空格键
2. 如果无效，鼠标移到左上角
3. 最后使用"停止"按钮

#### 技巧 3：配合观察

建议工作流程：
1. 开始绘画
2. 观察前几条线
3. 如有问题立即空格暂停
4. 调整后继续

#### 技巧 4：习惯养成

- 用空格代替鼠标点击
- 提高工作效率
- 减少操作步骤

### 常见问题

**Q: 为什么按空格没反应？**

A: 检查：
1. 是否安装了 `pynput` 库？
2. 程序启动时有没有错误提示？
3. 是否在绘画过程中按的？

**Q: 会不会和其他程序冲突？**

A: 只在绘画过程中监听，结束后自动停止，不会影响其他程序。

**Q: 可以用其他键代替空格吗？**

A: 当前版本固定为空格键。如需更改，可编辑 `main.py` 中的 `_on_key_press` 方法。

**Q: Mac/Linux 支持吗？**

A: `pynput` 库跨平台，理论上支持。但未充分测试，建议在 Windows 上使用。
