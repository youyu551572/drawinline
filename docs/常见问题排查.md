# 常见问题排查指南

## 问题1：处理图片后画布空白 ❌

### 症状
- 点击"处理图片"按钮
- 等待处理完成
- 右侧预览画布显示空白
- 没有任何线条显示

### 原因
可能的原因：
1. **细化算法过于激进**（v1.0.5问题）
2. **参数设置不当**
3. **图片本身线条太少**
4. **阈值设置过高**

### 解决方案

#### 方案1：确认使用v1.0.5.1或更高版本 ✅

v1.0.5.1已修复此问题。检查版本：
```python
# 查看 imgprocess.py 第71行附近
if cv2.countNonZero(thinned) < cv2.countNonZero(edges) * 0.5:
    # 如果是0.5说明已修复
    # 如果是0.3说明是旧版本
```

**更新方法**：
- 下载最新的 `imgprocess.py`
- 替换旧文件
- 重启程序

#### 方案2：调整参数 🎛️

降低边缘检测阈值：
```
阈值1: 从50降至30
阈值2: 从150降至100
模糊核: 保持5或降至3
```

**操作步骤**：
1. 点击 🟢 简单模式
2. 手动微调阈值1和阈值2
3. 重新点击"处理图片"

#### 方案3：检查图片本身 🖼️

**测试步骤**：
```
1. 选择一张明确有线条的图片
2. 例如：简笔画、Logo、黑白线条图
3. 如果这类图片也无法识别，是程序问题
4. 如果能识别，说明原图片线条太淡
```

**图片要求**：
- ✅ 清晰的边缘
- ✅ 高对比度
- ✅ 线条明显
- ❌ 模糊照片
- ❌ 低对比度
- ❌ 渐变色彩

## 问题2：拖动框选时卡顿 🐌

### 症状
- 点击"框选绘画区域"
- 拖动鼠标创建选择框
- 画面卡顿、不流畅
- 预览线条延迟

### 原因
- 线条数量过多
- 预览更新频率过高
- 电脑性能限制

### 解决方案

#### 确认使用v1.0.5或更高版本 ✅

v1.0.5已优化性能，包含：
- 节流机制（50ms）
- 线条采样（最多100条）
- 点数简化（每条20点）

**检查方法**：
```python
# 查看 area_selector.py
self.preview_interval = 0.05  # 应该有这一行
max_strokes = 100  # 应该有这一行
```

#### 临时解决方案 🔧

如果仍然卡顿：
1. **增加简化程度**：将简化程度设为5.0
2. **提高最小长度**：将最小长度设为100
3. **减少线条数量**：调整参数让识别出更少线条

## 问题4：双线条问题 ═══

### 症状
- 图片处理后
- 预览中同一条边显示为两条线
- 绘画时画了两遍

### 说明
这是边缘检测的固有特性，无法完全消除。

### 缓解方案

#### v1.0.5.1的温和细化 ✅

当前版本使用温和的细化算法，可以减少但不能消除双线条。

#### 手动参数调整 🎛️

**方法1：提高阈值**
```
阈值1: 提高10-20
阈值2: 提高20-30
```
更高的阈值会忽略较弱的边缘，减少双线条。

**方法2：增加模糊**
```
模糊核: 从5增至7或9
```
更大的模糊会合并接近的边缘。

**方法3：使用简化**
```
简化线条: 开启
简化程度: 3.0-5.0
```
简化会合并相近的点。

## 问题5：绘画位置不准确 📍

### 症状
- 框选了区域
- 但绘画位置偏移
- 与预览不一致

### 原因
- 主窗口遮挡导致框选不准
- 目标程序窗口移动了

### 解决方案

#### v1.0.4+的自动最小化 ✅

v1.0.4及以上会自动最小化主窗口。

#### 操作建议 📝

```
1. 打开目标绘画程序
2. 调整到想要的位置和大小
3. 点击"框选绘画区域"
4. 主窗口自动最小化
5. 精确框选绿色预览线条
6. 按Enter确认
7. 开始绘画前不要移动目标程序
```

## 问题6：安装pynput后仍无法使用空格键 ⌨️

### 症状
- 已安装pynput
- 但空格键暂停不生效
- 只能点按钮暂停

### 检查步骤

#### 1. 确认安装
```bash
pip list | findstr pynput
# 应该显示：pynput  1.7.6
```

#### 2. 重启程序
安装后必须重启程序才生效。

#### 3. 检查权限
某些安全软件可能阻止键盘监听。

#### 4. 查看控制台
```
如果启动时显示：
"提示：安装 pynput 库可启用空格键暂停功能"
说明导入失败。
```

### 解决方案

```bash
# 重新安装
pip uninstall pynput
pip install pynput==1.7.6

# 重启程序
python main.py
```

## 问题7：处理大图片很慢 🕐

### 症状
- 选择大尺寸图片（>2000px）
- 处理时间很长
- 程序似乎卡住

### 说明
这是正常现象，图片越大处理越慢。

### 解决方案

#### 方案1：缩小图片 📏
```
建议尺寸：800-1200px
最大尺寸：2000px
```

使用图片编辑软件预先缩小。

#### 方案2：调整参数 ⚡
```
模糊核: 增大到9-11
简化程度: 提高到5.0
最小长度: 提高到100
```
这会加快处理但可能丢失细节。

#### 方案3：耐心等待 ⏳
```
800px图片：1-2秒
1500px图片：5-10秒
3000px图片：30-60秒
```

## 问题8：控制台出现错误信息 ⚠️

### 常见错误

#### 错误1：无法读取图片
```
ValueError: 无法读取图片: xxx
```
**原因**：文件路径包含特殊字符或文件损坏
**解决**：
- 检查路径是否正确
- 尝试复制到简单路径（如桌面）
- 确认文件格式支持

#### 错误2：cv2相关错误
```
cv2.error: ...
```
**原因**：OpenCV处理异常
**解决**：
- 检查图片是否损坏
- 尝试转换图片格式
- 调整参数重试

### 步骤1：版本检查
```

```

```
├─ 提高阈值（70/200）
├─ 增加模糊核（7）
└─ 启用简化（3.0）
```
