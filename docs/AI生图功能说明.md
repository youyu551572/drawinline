# AI生图功能说明

## 📖 功能概述

YouYu自动绘画现已集成AI生图功能，可以通过文字描述自动生成简笔画素材，无需手动寻找图片。

## 🎯 主要特性

### 1. 文字生成图片
- 输入文字描述，AI自动生成简笔画
- 支持中文描述
- 自动优化为简笔画风格

### 2. 快速选择模板
- 小猫：一只可爱的小猫，简笔画风格，黑白线条
- 房子：简单的房子，线条画，轮廓清晰
- 花朵：一朵简单的花，线条画风格
- 笑脸：简单的笑脸表情，圆形轮廓

### 3. 生成历史管理
- 自动保存所有生成的图片
- 显示最近5条生成记录
- 支持快速重新使用历史图片

### 4. 一键使用
- 生成成功后可直接用于绘画
- 自动加载到软件中
- 无需手动选择文件

## 🚀 使用方法

### 步骤1：打开AI生图分栏
1. 启动YouYu自动绘画
2. 点击左侧的"AI生图"标签页

### 步骤2：输入描述
**方式A：手动输入**
1. 在输入框中输入您想要的简笔画描述
2. 例如："一只坐着的小猫"、"简单的房子轮廓"

**方式B：快速选择**
1. 点击下方的快速选择按钮
2. 系统会自动填入预设描述

### 步骤3：生成图片
1. 点击"生成简笔画"按钮
2. 等待AI生成（通常需要5-15秒）
3. 生成成功后会弹出提示框

### 步骤4：使用图片
**选项A：直接用于绘画**
1. 在提示框中点击"用于绘画"
2. 系统自动加载图片
3. 切换到"处理"标签页
4. 点击"处理图片"按钮

**选项B：查看图片**
1. 在提示框中点击"打开图片"
2. 系统会打开文件夹并选中图片
3. 可以查看、编辑或分享图片

**选项C：从历史记录使用**
1. 在"生成历史"区域查看之前生成的图片
2. 点击对应图片的"使用"按钮
3. 系统自动加载该图片

## 💡 使用技巧

### 1. 描述要具体
❌ 不好的描述："一个东西"
✅ 好的描述："一只坐着的小猫，简笔画风格"

### 2. 强调简笔画风格
- 在描述中加入"简笔画"、"线条画"、"黑白"等关键词
- 例如："一朵花，简笔画风格，黑白线条"

### 3. 保持描述简洁
- 避免过于复杂的描述
- 专注于主要物体和特征
- 例如："简单的房子轮廓"而不是"有红色屋顶、蓝色墙壁、两扇窗户的房子"

### 4. 利用快速选择
- 如果不确定如何描述，先试试快速选择按钮
- 可以在快速选择的基础上修改描述

## 🔧 技术说明

### API服务
- 使用Pollinations.ai免费API
- 完全免费，无需注册
- 无使用次数限制

### 图片保存
- 保存位置：`软件目录/ai_generated/`
- 文件格式：PNG
- 文件命名：`ai_generated_时间戳.png`

### 网络要求
- 需要连接互联网
- 建议网络稳定
- 生成时间取决于网络速度

## ❓ 常见问题

### Q1: 生成失败怎么办？
**A:** 可能的原因和解决方法：
- 网络连接问题：检查网络连接
- API服务繁忙：稍后重试
- 描述不合适：尝试修改描述

### Q2: 生成的图片不满意？
**A:** 可以尝试：
- 修改描述，更具体或更简洁
- 多次生成，选择最满意的
- 使用快速选择模板作为参考

### Q3: 图片保存在哪里？
**A:** 
- 保存在软件目录的`ai_generated`文件夹
- 生成成功后可以点击"打开图片"查看位置

### Q4: 可以生成彩色图片吗？
**A:** 
- 当前版本专注于简笔画（黑白线条）
- 这种风格最适合自动绘画
- 未来版本可能支持更多风格

### Q5: 生成需要多长时间？
**A:** 
- 通常5-15秒
- 取决于网络速度和API服务器负载
- 请耐心等待，不要重复点击

## 📝 注意事项

1. **网络连接**：需要稳定的网络连接
2. **描述规范**：避免敏感或不当内容
3. **版权说明**：生成的图片仅供个人使用
4. **存储空间**：定期清理不需要的历史图片
