### 3. 仿真人绘画行为

#### 3.1 动态速度调整

**根据距离调整速度**：
```python
# 计算两点间距离
distance = ((x2-x1)**2 + (y2-y1)**2)**0.5

# 模拟真人：短距离快，长距离慢
if distance < 5:
    speed = base_speed * 0.5  # 短线条快速
elif distance > 20:
    speed = base_speed * 1.5  # 长线条稍慢
else:
    speed = base_speed        # 正常速度
```

**原理**：
- 真人画短线时手腕动作快
- 画长线时需要更稳定的控制
- 速度变化更自然

#### 3.2 自然停顿

**模拟真人的停顿**：
```python
# 落笔前准备
time.sleep(0.1)  # 准备落笔

# 落笔停顿
mouse_down()
time.sleep(0.05)  # 落笔压力稳定

# 抬笔停顿
mouse_up()
time.sleep(0.08)  # 抬笔缓冲
```

#### 3.3 智能笔画衔接

**根据下一笔画调整延迟**：
```python
if len(next_stroke) > 50:
```

- 合并相近的点
- 跳过重复点
