# v2.0.31 截图识别功能说明

## 📸 功能概述

截图识别功能允许用户直接框选桌面区域进行截图，无需保存文件即可识别线条。适合快速识别网页、软件界面、设计稿等内容。

---

## 🎯 使用方法

### 1. 点击截图识别按钮
在"📁 图片"标签页中，点击"📸 截图识别"按钮

### 2. 框选识别区域
- 程序会最小化主窗口
- 出现半透明全屏黑色遮罩
- 使用鼠标拖动框选要识别的区域
- 实时显示框选区域的尺寸

### 3. 确认或取消
- **Enter键**：确认截图并开始识别
- **ESC键**：取消操作
- 最小框选尺寸：10×10像素

### 4. 自动识别
- 截图后自动调用图像处理
- 识别线条并在预览区域显示
- 后续操作与上传图片相同

## ⚙️ 技术实现

### 核心模块

**screenshot_selector.py**
```python
class ScreenshotSelector:
    - 透明全屏窗口
    - 鼠标拖动框选
    - PIL.ImageGrab截图
    - 返回numpy数组
```

### 工作流程

```
点击按钮
    ↓
最小化主窗口
    ↓
显示透明框选界面
    ↓
用户拖动框选区域
    ↓
按Enter确认
    ↓
隐藏框选窗口
    ↓
PIL截取指定区域
    ↓
转换为numpy数组（BGR）
    ↓
传给ImageProcessor
    ↓
自动识别处理
    ↓
显示预览结果
```

### 关键代码

**截图实现**：
```python
# 截取指定区域（PIL）
screenshot_pil = ImageGrab.grab(bbox=(x1, y1, x2, y2))

# 转换为numpy数组
screenshot_rgb = np.array(screenshot_pil)

# 转为OpenCV格式（BGR）
screenshot_bgr = screenshot_rgb[:, :, ::-1].copy()
```

**传给处理器**：
```python
# 创建处理器
self.image_processor = ImageProcessor()

# 直接设置图像数组
self.image_processor.image = screenshot_array

# 自动处理
self.process_image()
```

## ⚠️ 注意事项

### 1. 窗口遮挡
截图前主窗口会自动最小化，避免遮挡要截取的内容。

### 2. 延迟时间
确认后会有0.1秒延迟，确保框选窗口完全隐藏。

### 3. 最小尺寸
框选区域必须大于10×10像素，否则会提示重新框选。

### 4. 内存占用
大面积截图会占用较多内存，建议框选实际需要的区域。

### 5. 多显示器
支持多显示器，可以在任意显示器上框选。

## 🐛 常见问题

### Q: 截图后窗口不能恢复？
A: 检查是否有其他窗口置顶，手动点击任务栏图标恢复。

### Q: 框选框看不清？
A: 背景透明度为30%，如果背景太暗可能不明显，尝试在亮色区域框选。

### Q: 能截取全屏吗？
A: 可以，但建议只截取需要识别的部分，提高处理速度。

### Q: 支持多显示器吗？
A: 支持，PIL会自动处理多显示器坐标。
