scroll_content = QWidget()
scroll_layout = QVBoxLayout(scroll_content)

# 添加内容...

scroll_area.setWidget(scroll_content)

### 3. 收款码加载

```python
# 加载第一张收款码
qrcode1_label = QLabel()
qrcode1_path = "1763310716369.jpg"
if os.path.exists(qrcode1_path):
    pixmap1 = QPixmap(qrcode1_path)
    scaled_pixmap1 = pixmap1.scaled(
        140, 140, 
        Qt.KeepAspectRatio,           # 保持宽高比
        Qt.SmoothTransformation       # 平滑缩放
    )
    qrcode1_label.setPixmap(scaled_pixmap1)
```

## ⚡ 性能优化

### QPixmap缩放
- 使用 `Qt.KeepAspectRatio` 保持图片比例
- 使用 `Qt.SmoothTransformation` 平滑缩放
- 避免图片失真

### 滚动性能
- `setWidgetResizable(True)` 自适应大小
- 无边框设计减少渲染开销
- 内容动态加载，按需显示
