## 核心算法

### 1. 边缘检测算法

#### Canny 边缘检测

**原理**：
1. 高斯滤波去噪
2. 计算梯度幅值和方向
3. 非极大值抑制
4. 双阈值检测
5. 边缘连接

**实现代码**：
```python
# 灰度转换
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 高斯模糊
blurred = cv2.GaussianBlur(gray, (kernel_size, kernel_size), 0)

# Canny边缘检测
edges = cv2.Canny(blurred, threshold1, threshold2)
```

**参数说明**：
- `kernel_size`: 必须为奇数，控制模糊程度
- `threshold1`: 低阈值，用于边缘连接
- `threshold2`: 高阈值，用于确定强边缘

**算法特点**：
- 准确率高
- 抗噪声能力强
- 边缘定位精确
- 单像素边缘输出

### 2. 轮廓提取算法

#### findContours 算法

**原理**：
- 基于边界跟踪算法
- 从边缘图像中提取连续的边界点
- 采用链式表示法存储

**实现代码**：
```python
contours, hierarchy = cv2.findContours(
    edges,
    cv2.RETR_LIST,      # 检索所有轮廓
    cv2.CHAIN_APPROX_SIMPLE  # 压缩轮廓
)
```

**检索模式**：
- `RETR_LIST`: 提取所有轮廓，不建立层级关系
- `RETR_TREE`: 提取所有轮廓，建立完整层级
- `RETR_EXTERNAL`: 只提取最外层轮廓

**近似方法**：
- `CHAIN_APPROX_NONE`: 存储所有边界点
- `CHAIN_APPROX_SIMPLE`: 压缩水平、垂直和对角线段

**过滤策略**：
```python
# 计算轮廓周长
length = cv2.arcLength(contour, False)

# 过滤太短的轮廓
if length > min_length:
    filtered_contours.append(contour)
```

### 3. 线条简化算法

#### Douglas-Peucker 算法

**原理**：
1. 连接曲线首尾两点作为基线
2. 找到距离基线最远的点
3. 如果距离大于阈值，保留该点并递归处理两段
4. 如果距离小于阈值，丢弃中间所有点

**算法步骤**：
```
1. 输入：点序列 [P1, P2, ..., Pn]，阈值 epsilon
2. 找到距离 P1-Pn 连线最远的点 Pmax
3. 如果 distance(Pmax, P1-Pn) > epsilon:
     递归处理 [P1, ..., Pmax]
     递归处理 [Pmax, ..., Pn]
   否则:
     返回 [P1, Pn]
```

**实现代码**：
```python
epsilon_value = epsilon
approx = cv2.approxPolyDP(contour, epsilon_value, False)
```

**参数影响**：
- epsilon小：保留更多点，精度高
- epsilon大：简化更多，速度快

**复杂度分析**：
- 时间复杂度：O(n log n)（平均情况）
- 空间复杂度：O(n)

### 4. 路径规划算法

#### 最近邻策略

**目标**：减少笔画之间的移动距离

**策略**：
1. 按线条长度排序（先画长线）
2. 每次选择距离当前位置最近的未画线条
3. 考虑线条的起点和终点方向

**伪代码**：
```
current_pos = (0, 0)
undrawn_strokes = all_strokes
drawn_order = []

while undrawn_strokes:
    nearest = find_nearest_stroke(current_pos, undrawn_strokes)
    drawn_order.append(nearest)
    undrawn_strokes.remove(nearest)
    current_pos = nearest.end_point
```

**优化空间**：
- 可以使用贪心算法进一步优化
- 考虑使用遗传算法求近似最优解

## 技术细节

### 1. OpenCV 图像处理

#### 图像格式转换

**BGR to Gray**：
```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
```

**原理**：
```
Gray = 0.299*R + 0.587*G + 0.114*B
```

#### 高斯滤波

**数学公式**：
```
G(x,y) = (1/(2πσ²)) * exp(-(x²+y²)/(2σ²))
```

**特点**：
- 平滑图像
- 去除高斯噪声
- 为边缘检测做准备

**kernel_size 选择**：
- 3x3: 轻微模糊
- 5x5: 标准模糊
- 7x7+: 强模糊
