## 📊 技术原理

### 为什么降低Canny阈值？

```
Canny边缘检测原理：
- threshold1（低阈值）：弱边缘的最低梯度
- threshold2（高阈值）：强边缘的最低梯度

threshold1: 70 → 60
效果：
- 更多弱边缘被检测到
- 线条更完整
- 细节更丰富
```

### 为什么降低保留阈值？

```
细化算法会减少像素数量：
- Zhang-Suen通常减少60-80%
- 单次腐蚀通常减少30-50%

降低保留阈值（25%→20%，30%→25%）：
- 更宽松的判断标准
- 更多图片能通过细化
- 减少回退到闭运算的情况
```

```
    ↓

```
