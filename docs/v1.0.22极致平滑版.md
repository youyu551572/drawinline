## 💡 算法细节

### CLAHE算法

```python
def apply_clahe(gray_image):
    # 创建CLAHE对象
    clahe = cv2.createCLAHE(
        clipLimit=2.0,      # 对比度限制
        tileGridSize=(8,8)  # 网格大小
    )
    
    # 应用CLAHE
    enhanced = clahe.apply(gray_image)
    return enhanced
```

**参数说明**：
- `clipLimit`：对比度限制（防止过度增强）
- `tileGridSize`：局部网格大小

### 二次样条平滑

```python
def double_spline_smooth(points):
    # 第1次：强力平滑
    s1 = len(points) * 2.0
    tck1, u1 = splprep([x, y], s=s1, k=3)
    
    # 生成密集点
    num = int(len(points) * 1.5)
    smooth1_x, smooth1_y = splev(np.linspace(0, 1, num), tck1)
    
    # 第2次：轻度平滑（修饰）
    s2 = num * 0.5
    tck2, u2 = splprep([smooth1_x, smooth1_y], s=s2, k=3)
    
    # 生成最终点
    final_x, final_y = splev(np.linspace(0, 1, len(points)), tck2)
    
    return list(zip(final_x, final_y))
```
