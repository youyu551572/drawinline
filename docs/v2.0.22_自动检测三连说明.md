## 🤖 功能概述

实现使用Selenium自动检测B站三连状态，根据按钮的class属性判断是否完成点赞/投币/收藏。

### 核心特性

1. **Selenium自动检测**：自动打开浏览器解析页面
2. **检测class状态**：检查按钮class是否包含'on'
3. **自动启用功能**：三连完成后自动启用截图识别按钮
4. **降级处理**：失败时自动切换为手动验证
5. **详细反馈**：显示每个按钮的检测结果

---

## 🔍 检测原理

### B站三连按钮HTML结构

**未点赞状态**：
```html
<div class="video-like video-toolbar-left-item" data-v-8c353132="">
    <!-- 点赞图标和文字 -->
</div>
```

**已点赞状态**：
```html
<div class="video-like video-toolbar-left-item on" data-v-8c353132="">
    <!-- 点赞图标和文字 -->
</div>
```

**关键区别**：
- 未点赞：class="video-like video-toolbar-left-item"
- 已点赞：class="video-like video-toolbar-left-item **on**"

---

### 检测逻辑

```python
# 1. 查找元素
like_btn = driver.find_element(By.CLASS_NAME, "video-like")
coin_btn = driver.find_element(By.CLASS_NAME, "video-coin")
fav_btn = driver.find_element(By.CLASS_NAME, "video-fav")

# 2. 获取class属性
like_class = like_btn.get_attribute("class")
coin_class = coin_btn.get_attribute("class")
fav_class = fav_btn.get_attribute("class")

# 3. 检查是否包含'on'
liked = "on" in like_class     # True/False
coined = "on" in coin_class    # True/False
favorited = "on" in fav_class  # True/False

# 4. 判断三连
if liked and coined and favorited:
    # 三连完成
    screenshot_btn.setEnabled(True)
else:
    # 未完成三连
    screenshot_btn.setEnabled(False)
```

### 2. 自动检测函数

```python
def _auto_detect_bilibili_status(self):
    """使用selenium自动检测三连状态"""
    driver = None
    try:
        # 配置Chrome选项
        chrome_options = Options()
        chrome_options.add_argument('--start-maximized')
        
        # 创建浏览器实例
        self.update_status("正在打开浏览器检测...", "info")
        driver = webdriver.Chrome(options=chrome_options)
        driver.get(self.bilibili_url)
        
        # 等待页面加载
        self.update_status("等待页面加载...", "info")
        WebDriverWait(driver, 10).until(
            EC.presence_of_element_located((By.CLASS_NAME, "video-toolbar-left"))
        )
        
        # 等待一会儿确保页面完全加载
        import time
        time.sleep(2)
        
        # 检测点赞状态
        like_btn = driver.find_element(By.CLASS_NAME, "video-like")
        liked = "on" in like_btn.get_attribute("class")
        
        # 检测投币状态
        coin_btn = driver.find_element(By.CLASS_NAME, "video-coin")
        coined = "on" in coin_btn.get_attribute("class")
        
        # 检测收藏状态
        fav_btn = driver.find_element(By.CLASS_NAME, "video-fav")
        favorited = "on" in fav_btn.get_attribute("class")
        
        # 关闭浏览器
        driver.quit()
        
        # 判断是否三连
        if liked and coined and favorited:
            # 已完成三连
            self.bilibili_liked = True
            self.screenshot_btn.setEnabled(True)
            # 显示成功对话框
        else:
            # 未完成三连
            self.bilibili_liked = False
            self.screenshot_btn.setEnabled(False)
            # 显示未完成对话框
            
    except Exception as e:
        # 检测失败，降级为手动验证
        print(f"自动检测失败: {e}")
        if driver:
            driver.quit()
        self._manual_verify_bilibili()
```

### 3. 降级处理

```python
def _manual_verify_bilibili(self):
    """手动验证三连状态"""
    reply = QMessageBox.question(
        self,
        "手动确认三连状态",
        "自动检测功能不可用\n\n"
        "已为您打开B站视频\n"
        "请检查是否已完成三连：\n\n"
        "❤️ 点赞\n"
        "💎 投币\n"
        "⭐ 收藏\n\n"
        "是否已完成三连？",
        QMessageBox.Yes | QMessageBox.No
    )
    
    if reply == QMessageBox.Yes:
        self.screenshot_btn.setEnabled(True)
    else:
        self.screenshot_btn.setEnabled(False)
```

## ⚠️ 注意事项

### 1. selenium依赖

**必需组件**：
- selenium库
- Chrome浏览器
- ChromeDriver（版本匹配）

**推荐使用webdriver-manager**：
自动下载和管理ChromeDriver版本

---

### 2. 网络要求

- 需要能访问B站
- 页面加载需要时间
- 10秒超时限制

---

### 3. 页面结构变化

**风险**：
B站可能更新页面结构，导致检测失败

**应对**：
- 自动降级为手动验证
- 不影响其他功能使用

---

### 4. 浏览器兼容性

**当前支持**：
- Chrome浏览器

**未来可扩展**：
- Firefox
- Edge
- Safari

## 💡 优势与局限

### 优势

1. **自动化**：无需手动确认
2. **准确**：直接检测class属性
3. **友好**：详细的检测结果
4. **健壮**：失败时自动降级
5. **透明**：显示每个按钮状态

---

### 局限

1. **依赖多**：需要selenium和ChromeDriver
2. **速度慢**：需要启动浏览器（约5秒）
3. **可能失败**：网络问题或页面变化
4. **维护成本**：需要跟随B站页面更新
