# 打包发布指南

## 📦 **将软件打包为独立的exe文件**

让你的软件可以在任何Windows电脑上运行，无需安装Python环境。

---

## 🚀 **快速打包（推荐）**

### **方式一：双击打包（最简单）**

1. 双击运行 **`打包.bat`** 文件
2. 等待打包完成（约1-3分钟）
3. 在 `dist/` 文件夹找到 `YouYu自动绘画.exe`

### **方式二：命令行打包**

```bash
# 1. 安装打包工具
pip install pyinstaller

# 2. 执行打包
python build_exe.py

# 3. 找到生成的exe
# 位置：dist/YouYu自动绘画.exe
```

### **方式三：使用spec文件（自定义配置）**

```bash
pyinstaller YouYu自动绘画.spec
```

## 🔧 **打包参数说明**

### **PyInstaller常用参数**

| 参数 | 说明 | 示例 |
|------|------|------|
| `--onefile` | 打包成单个exe | ✅ 使用 |
| `--onedir` | 打包成文件夹 | 不推荐 |
| `--windowed` | 不显示控制台 | ✅ 使用 |
| `--console` | 显示控制台 | 调试时使用 |
| `--icon` | 设置图标 | `.ico`文件 |
| `--add-data` | 包含额外文件 | 图片、配置 |
| `--name` | exe名称 | 中文可用 |

### **减小体积的方法**

```python
# 排除不需要的模块
--exclude-module=matplotlib
--exclude-module=pandas
--exclude-module=scipy
--exclude-module=jupyter

# 使用UPX压缩（需要下载UPX）
--upx-dir=path/to/upx
```

## 🐛 **常见问题**

### **Q1: 打包失败，提示找不到模块**
```bash
# 解决方法：安装缺失的模块
pip install 模块名
```

### **Q2: exe文件太大（>100MB）**
```bash
# 检查是否包含了不必要的库
# 使用 --exclude-module 排除

# 或使用 --onedir 模式
pyinstaller --onedir modern_main.py
```

### **Q3: 其他电脑运行报错**
可能原因：
1. **缺少VC++运行库**
   - 解决：让用户安装 [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)

2. **权限问题**
   - 解决：右键"以管理员身份运行"

3. **杀毒软件拦截**
   - 解决：添加到信任列表

### **Q4: 打包后图标不显示**
```python
# 确保图标文件存在
# 格式必须是 .ico
# 使用绝对路径或正确的相对路径
--icon=066fb186-3172-4c45-9c26-48873ea6665d.tmp.ico
```

### **Q5: 打包后收款码不显示**
```python
# 确保图片文件被包含
# 在 .spec 文件中添加
datas=[
    ('zfb.png', '.'),
    ('wx.png', '.'),
]
```

## 🎨 **自定义打包**

### **修改.spec文件**

如果需要更多自定义，编辑 `YouYu自动绘画.spec`：

```python
# 添加更多数据文件
datas=[
    ('066fb186-3172-4c45-9c26-48873ea6665d.tmp.ico', '.'),
    ('zfb.png', '.'),
    ('wx.png', '.'),
    ('config.json', '.'),  # 添加配置文件
],

# 添加隐藏导入
hiddenimports=[
    'PyQt5',
    'cv2',
    'your_module',  # 添加你的模块
],

# 修改exe名称
name='你的软件名',

# 修改图标
icon='your_icon.ico',
```

然后执行：
```bash
pyinstaller YouYu自动绘画.spec
```
