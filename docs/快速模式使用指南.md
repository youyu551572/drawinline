# 快速模式使用指南

## 简介

快速模式按钮让您无需手动调整复杂参数，一键设置适合不同图片的最佳参数组合。

## 三种模式

### 🟢 简单模式

**适用场景**：
- 线条清晰的简笔画
- 背景纯净的图标
- 黑白线条图
- 卡通图案

**参数配置**：
```
模糊核大小: 3
边缘检测阈值1: 30
边缘检测阈值2: 100
最小线条长度: 30
简化线条: 开启
简化程度: 3.0
```

**特点**：
- ✅ 识别速度快
- ✅ 线条清晰锐利
- ✅ 噪点少
- ⚠️ 不适合复杂图片

**示例图片类型**：
```
简笔画：  ⭐⭐⭐⭐⭐
Logo：    ⭐⭐⭐⭐⭐
漫画：    ⭐⭐⭐
照片：    ⭐
```

## 使用方法

### 基本步骤

```
1. 选择图片
   ↓
2. 点击对应的模式按钮
   ├─ 🟢 简单
   ├─ 🟡 中等
   └─ 🔴 复杂
   ↓
3. 参数自动设置
   ↓
4. （可选）手动微调
   ↓
5. 点击"处理图片"
```

### 详细说明

#### 步骤1：选择图片

点击"选择图片"按钮，选择要处理的图片文件。

#### 步骤2：选择模式

根据图片类型点击对应按钮：

| 图片类型 | 推荐模式 |
|---------|---------|
| 简笔画、Logo | 🟢 简单 |
| 普通图片 | 🟡 中等 |
| 照片、复杂图 | 🔴 复杂 |

#### 步骤3：自动设置

点击按钮后，所有参数滑块会自动调整到预设值。

#### 步骤4：微调（可选）

如果效果不理想，可以手动调整个别参数：
- 线条太粗 → 降低模糊核
- 线条太少 → 降低阈值
- 线条太碎 → 增加最小长度
- 线条太复杂 → 增加简化程度

#### 步骤5：处理

点击"处理图片"，查看右侧预览效果。

## 参数对比表

| 参数 | 简单 | 中等 | 复杂 |
|-----|------|------|------|
| 模糊核 | 3 | 5 | 7 |
| 阈值1 | 30 | 50 | 70 |
| 阈值2 | 100 | 150 | 200 |
| 最小长度 | 30 | 50 | 20 |
| 简化程度 | 3.0 | 2.0 | 1.0 |

**参数说明**：
- **模糊核**：越大越平滑，越小越锐利
- **阈值**：越低识别越多边缘
- **最小长度**：过滤短线条
- **简化程度**：越大越简化

## 使用技巧

### 技巧1：先试中等模式

不确定用哪个？先试中等模式：
```
中等模式 → 查看效果
├─ 效果好 ✓ → 直接使用
├─ 线条太少 → 试简单模式
└─ 细节不够 → 试复杂模式
```

### 技巧2：渐进调整

如果中等模式不满意：
```
简单 ← 中等 → 复杂
   ↑         ↓
   线条太多   线条太少
   细节过多   细节不够
```

### 技巧3：模式+微调

推荐工作流：
1. 选择接近的模式
2. 一键设置基础参数
3. 只微调1-2个参数
4. 快速得到最佳效果

### 技巧4：不同区域用不同模式

同一张图片的不同部分：
- 背景简单 → 简单模式
- 主体复杂 → 复杂模式
- 分次处理，分别绘画

## 常见问题

### Q1: 模式之间可以切换吗？

**A**: 可以随时切换。
- 点击任意模式按钮
- 参数立即更新
- 不影响已选择的图片

### Q2: 设置模式后还能手动调参数吗？

**A**: 完全可以。
- 模式只是快速预设
- 设置后所有滑块都可调整
- 没有任何限制

### Q3: 我能保存自定义参数吗？

**A**: 当前版本暂不支持。
- 但可以记录参数值
- 下次手动设置
- 未来版本会添加此功能

### Q4: 处理同类型图片都用同一模式吗？

**A**: 通常如此，但不绝对。
- 同类型图片推荐同一模式
- 但具体图片可能有差异
- 可根据预览效果调整

### Q5: 模式影响绘画速度吗？

**A**: 有一定影响。
- 简单模式：识别快，线条少，绘画快
- 复杂模式：识别慢，线条多，绘画慢
- 但主要取决于图片本身
