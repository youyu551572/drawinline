# 功能说明文档

## 系统概述

图片线条自动绘画工具是一个基于计算机视觉和自动化控制的Windows桌面应用程序，能够智能识别图片中的线条并通过自动控制鼠标实现精确绘画。

## 重要特性

### ✨ 完美支持中文路径

程序已优化图像读取和保存功能，**完全支持包含中文字符的文件路径**。无论图片存放在任何位置（如 `F:/代码类/自动绘画工具/素材库/图片.jpg`），都能正常识别和处理。

**技术实现**：
- 使用 `numpy.fromfile()` + `cv2.imdecode()` 替代 `cv2.imread()`
- 使用 `cv2.imencode()` + `tofile()` 替代 `cv2.imwrite()`
- 完全兼容 Unicode 路径

## 核心功能模块

### 1. 图像处理模块 (imgprocess.py)

#### 1.1 图像预处理

**功能描述**：对输入图片进行预处理，为线条识别做准备

**技术实现**：
- 灰度转换：将彩色图像转换为灰度图像
- 高斯模糊：使用可调节的核大小进行降噪处理
- Canny边缘检测：双阈值边缘检测算法

**可调参数**：
- `blur_kernel`：模糊核大小（1-15，必须为奇数）
  - 作用：控制图像平滑程度
  - 建议值：5（默认）
  - 较大值：适合噪点多的图片
  - 较小值：适合清晰图片

- `threshold1`：Canny低阈值（10-200）
  - 作用：边缘连接的最低梯度值
  - 建议值：50（默认）
  - 较大值：减少弱边缘
  - 较小值：检测更多细节

- `threshold2`：Canny高阈值（50-300）
  - 作用：确定强边缘的梯度值
  - 建议值：150（默认）
  - 通常为threshold1的2-3倍

#### 1.2 轮廓提取

**功能描述**：从边缘图像中提取完整的线条轮廓

**技术实现**：
- 使用OpenCV的`findContours`函数
- 采用`RETR_LIST`模式获取所有轮廓
- 使用`CHAIN_APPROX_SIMPLE`压缩水平、垂直和对角线段

**可调参数**：
- `min_length`：最小线条长度（10-200像素）
  - 作用：过滤过短的线条和噪点
  - 建议值：50（默认）
  - 较大值：只保留主要线条
  - 较小值：保留更多细节

#### 1.3 线条简化

**功能描述**：减少线条上的点数，提高绘画效率

**技术实现**：
- Douglas-Peucker算法：多边形曲线近似算法
- 保持线条形状的同时减少点数

**可调参数**：
- `simplify`：是否启用简化（布尔值）
- `epsilon`：简化程度（0.5-10）
  - 作用：控制简化的激进程度
  - 建议值：2.0（默认）
  - 较大值：更多简化，速度更快，精度降低
  - 较小值：保持更多细节，速度较慢

#### 1.4 预览功能

**功能描述**：可视化展示处理后的线条效果

**实现方式**：
- 白色背景上绘制黑色线条
- 支持缩放显示
- 可保存预览结果

### 2. 鼠标控制模块 (mctl.py)

#### 2.1 鼠标移动控制

**功能描述**：精确控制鼠标移动到指定位置

**技术实现**：
- 使用PyAutoGUI库
- 支持平滑移动和瞬移
- 坐标偏移系统支持

**关键方法**：
- `move_to(x, y, duration)`：移动到指定坐标
- `set_offset(x, y)`：设置绘画区域偏移量

#### 2.2 绘画执行

**功能描述**：按照线条路径自动绘画

**绘画流程**：
1. 移动到线条起点
2. 按下鼠标左键
3. 沿着点序列移动鼠标
4. 释放鼠标左键
5. 延迟后进入下一条线

**可调参数**：
- `speed`：绘画速度（0.001-0.02秒/点）
  - 作用：每个点的停留时间
  - 建议值：0.005（默认）
  - 较大值：绘画更慢但更准确
  - 较小值：绘画更快但可能不连续

- `delay_between_strokes`：笔画间延迟（秒）
  - 作用：每条线之间的暂停时间
  - 建议值：0.1（默认）

#### 2.3 安全机制

**紧急停止**：
- 鼠标移到屏幕左上角自动中止（PyAutoGUI FAILSAFE）

**暂停和继续**：
- 支持运行时暂停
- 可随时恢复绘画

**状态监控**：
- 实时检查暂停标志
- 支持外部控制信号

### 4. 区域选择器 (area_selector.py)

#### 4.1 功能概述

**目的**：提供可视化的绘画区域选择方式，让用户精确框选绘画位置。

**核心类**：`AreaSelectorV2`

**主要特性**：
- 全屏透明窗口
- 实时拖拽框选
- 红色矩形框显示
- 位置和尺寸实时显示
- 键盘快捷键支持

#### 4.2 技术实现

**窗口设置**：
```python
# 全屏设置
window.geometry(f"{screen_width}x{screen_height}+0+0")
window.attributes('-fullscreen', True)
window.attributes('-topmost', True)
window.attributes('-alpha', 0.5)  # 半透明
```

**绘制策略**：
- 黑色半透明背景（便于看清底层内容）
- 红色矩形框（宽度3像素）
- 黄色信息文字（位置和尺寸）
- 白色/绿色提示文字（操作说明）

**事件处理**：
- `<ButtonPress-1>`: 记录起始点
- `<B1-Motion>`: 实时绘制矩形
- `<ButtonRelease-1>`: 记录结束点
- `<Return>`: 确认选择（包括小键盘Enter）
- `<Escape>`: 取消选择

#### 4.3 使用流程

**步骤1：打开选择器**
```python
result = select_drawing_area()
```

**步骤2：框选区域**
- 窗口出现后，鼠标变为十字形
- 按住左键拖动鼠标
- 实时显示红色矩形框
- 显示当前位置和尺寸

**步骤3：确认或取消**
- 按 Enter 键：确认选择，返回 (x, y, width, height)
- 按 Esc 键：取消选择，返回 None
- 自动验证：区域宽高必须 > 10 像素

**步骤4：结果处理**
```python
if result:
    x, y, width, height = result
    # 使用选择的区域
else:
    # 用户取消了选择
```

#### 4.4 视觉效果

**顶部提示区**：
- 黑色背景，100像素高
- 白色大标题："📍 拖动鼠标框选绘画区域"
- 绿色副标题："按 Enter 确认 | 按 Esc 取消"

**信息显示区**：
- 左上角，黄色边框黑色背景
- 实时显示：位置(x, y)、尺寸(width × height)

**选择框**：

**场景1：精确定位**

**场景2：尺寸适配**

## 性能优化

### 提高处理速度

1. **启用线条简化**
   - 可减少50-80%的绘画点
   - 对效果影响较小

2. **增大简化程度**
   - epsilon值每增加1，点数减少约20-30%

3. **过滤短线条**
   - 增大min_length值
   - 减少无意义的小线段

### 提高绘画质量

1. **降低绘画速度**
   - 确保鼠标移动轨迹连续
   - 适用于要求高精度的场景

2. **优化图片预处理**
   - 提高图片对比度
   - 去除噪点
   - 调整尺寸

3. **选择合适的绘画工具**
   - 使用连续绘画模式的工具
   - 设置合适的画笔粗细

## 技术限制

### 当前限制

1. **仅支持单色线条**
   - 不识别颜色信息
   - 所有线条按黑色处理

2. **无填充支持**
   - 只绘制轮廓线
   - 不处理区域填充

3. **依赖目标程序**
   - 需要目标绘画程序支持鼠标操作
   - 对特殊输入法的程序可能不兼容

### 环境要求

1. **Windows系统**
   - PyAutoGUI在Windows上表现最佳
   - 需要管理员权限（某些情况）

2. **屏幕分辨率**
   - 建议1920x1080或更高
   - 低分辨率可能影响精度

3. **CPU和内存**
   - 图像处理需要一定计算资源
   - 大图片可能需要较多内存

## 故障排除

### 常见问题

1. **线条识别不准**
   - 检查原图质量
   - 调整Canny阈值
   - 尝试图片预处理

2. **绘画位置偏移**
   - 重新选择位置坐标
   - 检查目标程序窗口位置
   - 确保屏幕缩放为100%

3. **绘画不连续**
   - 降低绘画速度
   - 检查目标程序响应速度
   - 确保系统资源充足

4. **程序崩溃**
   - 检查依赖库版本
   - 查看错误日志
   - 尝试更小的图片
