# PyQt5现代化版本说明

## 🎨 概述

**YouYu自动绘画 - PyQt5现代版** 是原tkinter版本的全新升级，采用现代化UI设计，界面更美观、交互更流畅！

---

## ✨ 主要特性

### 🎯 现代化界面
- ✅ **Material Design风格**：扁平化、清爽的视觉设计
- ✅ **流畅动画**：可折叠面板带平滑过渡效果
- ✅ **响应式布局**：自适应窗口大小
- ✅ **状态反馈**：彩色状态提示（成功/警告/错误）

### 💫 优秀交互
- ✅ **可折叠面板**：所有功能区域可展开/收起
- ✅ **实时预览**：流畅的画布渲染
- ✅ **多线程处理**：不卡顿的图像处理和绘画
- ✅ **进度提示**：清晰的进度条和状态文字

### 🎨 美观设计
- ✅ **统一配色**：蓝色主题 + 语义化颜色
- ✅ **圆角边框**：柔和的视觉效果
- ✅ **阴影效果**：立体感UI组件
- ✅ **图标按钮**：Emoji + 清晰文字

## 📖 使用指南

### 1️⃣ 主界面布局

```
┌─────────────────────────────────────────────────┐
│  🎨 YouYu自动绘画 - 现代版                      │
├──────────────┬──────────────────────────────────┤
│              │                                  │
│  左侧控制面板  │      右侧预览区域               │
│              │                                  │
│  📊 系统信息  │      📺 预览                    │
│  📁 图片文件  │                                  │
│  🎨 处理参数  │    [600×600画布]               │
│  🗌️ 绘画参数  │                                  │
│  💖 作者支持  │      信息显示区                 │
│              │                                  │
│  [进度条]    │                                  │
│  [状态标签]  │                                  │
└──────────────┴──────────────────────────────────┘
```

### 2️⃣ 功能面板

#### 📊 系统信息
- 显示屏幕分辨率
- 可折叠/展开

#### 📁 图片文件
- 选择要处理的图片
- 支持格式：PNG, JPG, JPEG, BMP
- 显示文件路径

#### 🎨 处理参数
- **模糊核**：图像平滑程度（1-15）
- **阈值1/2**：边缘检测敏感度（10-300）
- **最小长度**：过滤短线条（10-200）
- **简化线条**：减少点数，提升速度
- **简化程度**：控制简化强度（0.5-10）

#### 🗌️ 绘画参数
- **绘画区域**：框选目标位置和尺寸
- **速度**：绘画移动速度（0.001-0.02）
- **倒计时**：开始前等待时间（0-60秒）
- **控制按钮**：开始/暂停/停止

### 3️⃣ 操作流程

**步骤1：选择图片**
```
点击"📂 选择图片" → 选择文件 → 确认加载
```

**步骤2：调整参数**
```
拖动滑块调整处理参数 → 获得最佳识别效果
```

**步骤3：处理图片**
```
点击"⚡ 处理图片" → 等待处理完成 → 查看预览
```

**步骤4：框选区域**
```
点击"📍 框选绘画区域" → 拖动鼠标框选 → 松开确认
```

**步骤5：开始绘画**
```
点击"▶️ 开始" → 倒计时 → 自动绘画
```

## 🔧 技术实现

### 核心技术栈

- **GUI框架**：PyQt5
- **图像处理**：OpenCV + NumPy
- **鼠标控制**：PyAutoGUI + pynput
- **多线程**：QThread（防止界面卡顿）

### 架构设计

```python
ModernDrawingApp (主窗口)
├── left_panel (左侧面板)
│   ├── CollapsibleBox (系统信息)
│   ├── CollapsibleBox (图片文件)
│   ├── CollapsibleBox (处理参数)
│   ├── CollapsibleBox (绘画参数)
│   └── CollapsibleBox (作者支持)
├── right_panel (右侧面板)
│   └── PreviewCanvas (预览画布)
├── ImageProcessThread (处理线程)
└── DrawingThread (绘画线程)
```

### 自定义组件

**CollapsibleBox（可折叠面板）**
```python
- 标题按钮：可点击切换
- 内容区域：动态显示/隐藏
- 动画效果：QPropertyAnimation
- 箭头指示：▼展开 / ▶折叠
```

**PreviewCanvas（预览画布）**
```python
- 继承自QLabel
- 使用QPainter绘制
- 抗锯齿渲染
- 采样优化性能
```

## 💡 使用技巧

### 1. 参数调优

**获得清晰线条**
- 提高阈值1和阈值2
- 增加最小长度
- 减少模糊核

**获得更多细节**
- 降低阈值1和阈值2
- 减少最小长度
- 关闭简化线条

**加快绘画速度**
- 开启简化线条
- 增加简化程度
- 提高绘画速度

### 2. 面板管理

**节省空间**
```
处理图片时：收起"系统信息"和"作者支持"
绘画时：收起"处理参数"
只看预览：收起"绘画参数"
```

**快速切换**
```
点击标题栏任意位置即可展开/收起
箭头图标自动提示当前状态
```

### 3. 性能优化

**预览优化**
- 自动限制显示线条（最多500条）
- 长线条自动采样（最多50个点）
- 不影响实际绘画精度

**多线程设计**
- 图像处理在独立线程
- 绘画执行在独立线程
- 界面始终保持响应

## 🐛 常见问题

### Q: 如何安装PyQt5？
```bash
pip install PyQt5
```

### Q: 界面显示模糊？
- Windows：程序会自动设置DPI感知
- 如仍模糊，右键.py文件 → 属性 → 兼容性 → 高DPI设置

### Q: 按钮点击无反应？
- 检查是否先选择了图片
- 查看状态栏提示信息
- 确认所有参数已设置

### Q: 可以同时运行两个版本吗？
- 可以！tkinter版和PyQt5版完全独立
- 共享imgprocess.py和mctl.py核心逻辑
- 互不干扰
