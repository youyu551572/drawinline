## 🎯 **最佳使用策略**

### 1. 推荐提示词格式

**✅ 推荐** (成功率高):
```
cat drawing
dog sketch  
house art
flower drawing
bird sketch
```

**⚠️ 避免** (容易失败):
```
鳄鱼简笔画 (中文可能有网络问题)
a very detailed complex cyberpunk city... (过长)
```

### 2. 使用技巧

**英文优先**:
- "cat" 而不是"猫"
- "house" 而不是"房子"
- "flower" 而不是"花"

**简短描述**:
- "cat drawing" ✅
- "cat, simple line drawing, black and white..." ❌

**耐心等待**:
- 系统会自动重试5种策略
- 每种策略最多重试5次
- 总共可能需要1-2分钟

## 💡 **如果还是失败**

### 常见原因
1. **Pollinations服务器负载高** (最常见)
2. **网络连接不稳定**
3. **提示词过于复杂**
4. **速率限制**

### 解决方案
1. **换个时间试试** (避开高峰期)
2. **使用英文提示词**
3. **简化描述**
4. **多试几次** (系统会自动重试)
