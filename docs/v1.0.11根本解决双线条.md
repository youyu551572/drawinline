# v1.0.11 根本解决双线条 - 自适应双路径处理

## 🎯 问题本质

### 用户的准确分析
> "双线条还是存在，是不是识别到图片中线条两边，识别成了两个线条。"

**完全正确！** 这正是Canny边缘检测的固有问题。

### Canny边缘检测的原理

```
原图（粗黑线条）：
    ████████████
    ████████████
    ████████████

Canny检测亮度变化：
    ────────────  ← 检测到上边缘（白→黑的变化）
    （中间空白）
    ────────────  ← 检测到下边缘（黑→白的变化）
    
结果：一条粗线变成了两条细线！
```

**核心问题**：
- Canny检测的是**边缘**（edge），不是**线条**（line）
- 对于粗线条，它会检测到**两个边缘**
- 任何后处理都只是"修补"，不能根本解决

---

## ✅ 根本解决方案：自适应双路径处理

### 核心思想

不是所有图片都适合用Canny！根据图片特征选择不同算法：

1. **粗线条图** → 直接二值化+骨架化（提取中心线）
2. **细线条/复杂图** → 传统Canny边缘检测

### 实现原理

```python
    cv2.THRESH_BINARY_INV,  # 线条变白色
    11, 2
)

# 计算线条占比

```

```
    ↓
```

## 🔧 参数说明

### 自适应阈值参数

```python
cv2.adaptiveThreshold(
    blurred, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,  # 高斯加权
    cv2.THRESH_BINARY_INV,  # 反转（线条变白）
    11,  # 邻域大小（必须是奇数）
```

| 2%-30% | 粗线条图 | 骨架化 |
