## 系统要求

### 硬件要求

- **处理器**：Intel Core i3 或同等级别以上
- **内存**：至少 4GB RAM（推荐 8GB）
- **硬盘空间**：至少 500MB 可用空间
- **显示器**：分辨率至少 1366x768（推荐 1920x1080）
- **鼠标**：标准鼠标或触控板

### 软件要求

- **操作系统**：Windows 7/8/10/11（64位）
- **Python**：Python 3.7 或更高版本
- **网络**：安装依赖包时需要网络连接

## 安装步骤

### 步骤 1：安装 Python

1. 访问 Python 官网：https://www.python.org/downloads/
2. 下载 Python 3.7 或更高版本
3. 运行安装程序
4. ⚠️ **重要**：勾选 "Add Python to PATH"
5. 点击 "Install Now"

**验证安装**：
```bash
python --version
```

### 步骤 2：下载项目

**方式 1：使用 Git**
```bash
git clone <项目地址>
cd drawinline-main
```

**方式 2：直接下载**
1. 下载项目 ZIP 文件
2. 解压到目标目录
3. 打开命令提示符，进入项目目录

### 步骤 3：创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
.venv\Scripts\activate

# 看到 (.venv) 前缀表示激活成功
```

**为什么使用虚拟环境？**
- 隔离项目依赖
- 避免版本冲突
- 便于管理

### 步骤 4：安装依赖包

```bash
# 确保虚拟环境已激活
pip install -r requirements.txt
```

**安装内容**：
- opencv-python：图像处理库
- numpy：数值计算库
- pyautogui：鼠标控制库
- Pillow：图像显示库

**如果安装遇到问题**：
```bash
# 使用国内镜像加速
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 步骤 5：验证安装

```bash
# 测试导入
python -c "import cv2, numpy, pyautogui; print('安装成功！')"
```

## 快速开始

### 5分钟快速体验

1. **启动程序**
```bash
python main.py
```

2. **选择测试图片**
   - 准备一张简单的简笔画图片
   - 点击"选择图片"按钮
   - 选择你的图片

3. **处理图片**
   - 保持默认参数
   - 点击"处理图片"
   - 查看右侧预览

4. **测试绘画**
   - 打开Windows自带的"画图"程序
   - 选择画笔工具
   - 将画图窗口放在屏幕左侧
   - 在程序中点击"选择位置"
   - 将鼠标移到画布左上角，等待5秒
   - 点击"开始绘画"
   - 确认提示框
   - 观察自动绘画过程

## 详细使用教程

### 教程 1：基础操作

#### 1.1 界面介绍

**左侧面板**：
- 文件选择：选择要处理的图片
- 图像处理参数：调整识别效果
- 绘画参数：控制绘画行为
- 控制按钮：开始/暂停/停止

**右侧面板**：
- 预览画布：显示识别结果
- 信息显示：显示统计信息

#### 1.2 选择图片

**支持的格式**：
- PNG（推荐）
- JPG/JPEG
- BMP
- GIF

**图片要求**：
- 清晰度：越清晰越好
- 尺寸：建议不超过2000x2000像素
- 对比度：线条与背景对比明显
- 内容：简单图案效果最佳

#### 1.3 处理图片

**调整参数**：

1. **模糊核大小**（默认：5）
   - 作用：降噪
   - 图片很清晰 → 减小到 3
   - 图片有噪点 → 增大到 7-9

2. **边缘检测阈值1**（默认：50）
   - 作用：控制边缘敏感度
   - 线条太少 → 减小到 30
   - 线条太多 → 增大到 70

3. **边缘检测阈值2**（默认：150）
   - 保持为阈值1的 2-3 倍

4. **最小线条长度**（默认：50）
   - 作用：过滤短线
   - 保留细节 → 减小到 30
   - 只要主线 → 增大到 100

5. **简化线条**（默认：开启）
   - 建议保持开启
   - 可大幅提高速度

6. **简化程度**（默认：2.0）
   - 快速绘画 → 增大到 3-5
   - 精确绘画 → 减小到 1-1.5

**处理结果**：
- 查看预览是否满意
- 查看检测到的线条数
- 查看绘画点数

**不满意？**
- 调整参数重新处理
- 可以多次尝试不同组合

### 教程 2：绘画设置

#### 2.1 选择绘画位置

**方法一：手动输入坐标**
1. 打开目标绘画程序
2. 记录画布左上角的屏幕坐标
3. 在"绘画位置X"和"Y"输入框输入坐标

**方法二：自动捕获**
1. 点击"选择位置"按钮
2. 快速将鼠标移到目标位置
3. 等待5秒，程序自动记录位置
4. 查看是否正确捕获

**如何找到坐标？**
- 使用Windows自带的截图工具
- 鼠标移到目标位置，查看坐标显示
- 或使用在线坐标查看工具

#### 2.2 调整绘画速度

**速度参数**（默认：0.005）

- **快速模式**：0.002-0.003
  - 适合：简单图案、测试
  - 优点：速度快
  - 缺点：可能不连续

- **标准模式**：0.005-0.008
  - 适合：大多数情况
  - 平衡速度和质量

- **精确模式**：0.01-0.02
  - 适合：复杂图案、重要作品
  - 优点：质量高
  - 缺点：耗时长

#### 2.3 设置倒计时

**倒计时时间**（默认：3秒）

- 作用：给你时间切换到绘画程序
- 建议：保持3-5秒
- 过短：可能来不及准备
- 过长：等待时间长

### 教程 3：开始绘画

#### 3.1 准备工作

**清单**：
- ✅ 图片已处理
- ✅ 预览效果满意
- ✅ 绘画位置已设置
- ✅ 目标程序已打开
- ✅ 画笔工具已选择
- ✅ 画笔颜色已设置
- ✅ 保存了当前工作（以防万一）

#### 3.2 执行绘画

1. 点击"开始绘画"按钮
2. 阅读确认对话框
3. 点击"是"确认
4. 程序窗口自动最小化
5. 倒计时开始
6. 自动绘画开始

#### 3.3 监控进度

- 进度条显示完成百分比
- 状态标签显示当前笔画数
- 可以观察绘画过程

#### 3.4 控制绘画

**暂停**：
- 点击"暂停"按钮
- 鼠标停止移动
- 点击"继续"恢复

**停止**：
- 点击"停止"按钮
- 立即中止绘画
- 无法恢复

**紧急停止**：
- 将鼠标快速移到屏幕左上角
- PyAutoGUI安全机制会中止程序

### 教程 4：高级技巧

#### 4.1 批量处理

**处理多张图片**：
1. 处理第一张图片
2. 记录满意的参数组合
3. 处理其他图片时直接应用相同参数

#### 4.2 分区域绘画

**大图片分割**：
1. 使用图片编辑软件将大图分成多个部分
2. 分别处理每个部分
3. 在不同位置绘画
4. 最终拼接成完整作品

#### 4.3 预处理图片

**使用图片编辑软件**：
- 调整对比度和亮度
- 转换为黑白图片
- 去除背景噪点
- 锐化边缘

**推荐软件**：
- GIMP（免费）
- Photoshop
- Paint.NET

## 常见问题

### Q1: 程序启动失败

**现象**：运行 python main.py 报错

**解决方法**：
```bash
# 检查Python版本
python --version

# 重新安装依赖
pip install --upgrade -r requirements.txt

# 检查是否在正确目录
dir  # 应该能看到 main.py
```

### Q2: 识别线条太多或太少

**线条太多**：
- 增大"边缘检测阈值1"（如从50到70）
- 增大"最小线条长度"（如从50到100）
- 增大"模糊核大小"（如从5到7）

**线条太少**：
- 减小"边缘检测阈值1"（如从50到30）
- 减小"最小线条长度"（如从50到30）

### Q3: 绘画位置不准确

**问题**：绘画偏离目标位置

**解决方法**：
1. 检查屏幕缩放设置（应为100%）
2. 使用"选择位置"功能重新捕获
3. 手动微调X、Y坐标
4. 确保目标程序窗口没有移动

### Q4: 绘画过程中断

**问题**：绘画突然停止

**可能原因**：
- 鼠标意外移到左上角（安全机制）
- 系统资源不足
- 目标程序无响应

**解决方法**：
- 避免触碰鼠标
- 关闭其他占用资源的程序
- 降低绘画速度
- 减少线条数量

### Q5: 绘制的线条不连续

**问题**：线条断断续续

**解决方法**：
1. 降低绘画速度（增大speed参数）
2. 检查目标程序性能
3. 确保选择了连续绘画模式的工具
4. 减少简化程度

### Q6: 内存占用过高

**问题**：处理大图片时内存不足

**解决方法**：
1. 使用图片编辑软件缩小图片尺寸
2. 增大简化程度减少点数
3. 增大最小线条长度
4. 关闭其他应用程序

**推荐的绘画程序**：

1. **Windows 画图**

   - 缺点：功能有限
   - 适合：测试、简单绘画

2. **Paint.NET**
   - 优点：功能丰富、免费

   - 适合：一般用途

3. **Krita**
   - 优点：专业、开源
   - 缺点：较重
   - 适合：艺术创作

4. **在线绘画工具**

   - 适合：演示

   - 使用高质量原图
   - 预处理去噪
   - 调整对比度

2. **参数调优**
   - 多次测试找最佳参数
   - 记录成功组合

3. **环境优化**
   - 关闭不必要的程序
   - 确保鼠标灵敏度适中

## 安全提示

⚠️ **重要安全建议**：

1. **首次使用测试**
   - 在不重要的文件中测试
   - 验证功能正常后再处理重要内容

2. **保存工作**
   - 绘画前保存当前工作
   - 避免意外导致数据丢失

3. **避免干扰**
   - 绘画过程中不要使用电脑
   - 关闭可能弹出的通知

4. **紧急停止**
   - 记住紧急停止方法
   - 鼠标移到左上角
