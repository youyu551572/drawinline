# 粗线条双边缘问题解决方案

## 🎯 问题分析

### 问题现象

用户反馈：即使使用了v1.0.7的骨架化算法，双线条问题仍然存在。

### 根本原因

您的分析**完全正确**！问题的根源是：

#### Canny边缘检测的特性

Canny算法检测的是**亮度变化的边界**，而不是线条的中心。

```
原图（粗线条，宽度5-10像素）：
┌────────────────┐
│                │
│   ██████████   │  ← 白色背景
│   ██████████   │  ← 黑色粗线条（5像素宽）
│   ██████████   │
│                │
└────────────────┘

Canny检测结果：
┌────────────────┐
│                │
│   ──────────   │  ← 上边缘
│                │
│   ──────────   │  ← 下边缘
│                │
└────────────────┘

结果：检测到两条平行线！
```

### 为什么骨架化不能完全解决

骨架化算法可以将**已经存在的双线条细化为单线条**，但有两个限制：

1. **间距问题**：如果双线条间距较大（>3像素），骨架化会分别细化两条线，而不是合并
2. **本质问题**：骨架化是"事后处理"，不能从根本上解决粗线条的双边缘问题

```
粗线条（10像素宽）Canny检测：
────────────────  ← 上边缘

（间距8像素）

────────────────  ← 下边缘

骨架化后：
────────────────  ← 仍然是两条线！
────────────────
```

## ✅ 解决方案：距离变换中心线提取

### 原理

**距离变换（Distance Transform）**：
- 计算每个前景像素到最近背景像素的距离
- 距离最大的点就是粗线条的**中心线**

### 算法流程

#### 步骤1：二值化
```python
# 将图像二值化，提取线条区域
_, binary = cv2.threshold(blurred, 127, 255, cv2.THRESH_BINARY_INV)

# 线条区域：白色（255）
# 背景区域：黑色（0）
```

#### 步骤2：检测是否为粗线条
```python
# 如果二值化后的区域远大于Canny边缘
# 说明线条较粗
if cv2.countNonZero(binary) > cv2.countNonZero(edges) * 2:
    # 是粗线条，使用距离变换
```

#### 步骤3：距离变换
```python
# 计算距离变换
dist_transform = cv2.distanceTransform(binary, cv2.DIST_L2, 5)

# 结果：每个像素的值表示到背景的距离
# 粗线条中心的距离值最大
```

#### 步骤4：提取中心线
```python
# 归一化到0-255
cv2.normalize(dist_transform, dist_transform, 0, 255, cv2.NORM_MINMAX)

# 阈值化：保留距离大于40%最大距离的像素
max_dist = np.max(dist_transform)
_, centerline = cv2.threshold(dist_transform, max_dist * 0.4, 255, cv2.THRESH_BINARY)

# centerline就是中心线
```

### 可视化示例

```
原图（粗黑线）：
┌─────────────────┐
│    ████████     │
│    ████████     │
│    ████████     │
└─────────────────┘

Canny边缘检测：
┌─────────────────┐
│    ────────     │  ← 上边缘
│                 │
│    ────────     │  ← 下边缘
└─────────────────┘

距离变换：
┌─────────────────┐
│    001110       │
│    012210       │  ← 数字表示距离
│    001110       │     中心距离最大(2)
└─────────────────┘

中心线提取（阈值>1）：
┌─────────────────┐
│                 │
│    ──────       │  ← 单条中心线！
│                 │
└─────────────────┘
```

## 🔧 实现细节

### 完整算法

```python
def preprocess(self, blur_kernel, threshold1, threshold2):
    # 1. 灰度化和模糊
    gray = cv2.cvtColor(self.original_image, cv2.COLOR_BGR2GRAY)
    blurred = cv2.GaussianBlur(gray, (blur_kernel, blur_kernel), 0)
    
    # 2. Canny边缘检测
    edges = cv2.Canny(blurred, threshold1, threshold2)
    
    # 3. 粗线条检测和中心线提取
    _, binary = cv2.threshold(blurred, 127, 255, cv2.THRESH_BINARY_INV)
    
    if cv2.countNonZero(binary) > cv2.countNonZero(edges) * 2:
        # 距离变换
        dist_transform = cv2.distanceTransform(binary, cv2.DIST_L2, 5)
        cv2.normalize(dist_transform, dist_transform, 0, 255, cv2.NORM_MINMAX)
        dist_transform = np.uint8(dist_transform)
        
        # 提取中心线
        max_dist = np.max(dist_transform)
        if max_dist > 10:  # 线条足够粗
            _, centerline = cv2.threshold(dist_transform, max_dist * 0.4, 255, cv2.THRESH_BINARY)
            
            if cv2.countNonZero(centerline) >= cv2.countNonZero(edges) * 0.3:
                edges = centerline
                print("检测到粗线条，已提取中心线")
    
    # 4. 骨架化
    skeleton = skeletonize(edges)
    
    return skeleton
```

### 参数说明

| 参数 | 含义 | 默认值 | 建议范围 |
|------|------|--------|---------|
| `binary * 2` | 粗线条检测阈值 | 2倍 | 1.5-3倍 |
| `max_dist > 10` | 最小线条宽度 | 10像素 | 5-15像素 |
| `max_dist * 0.4` | 中心线阈值 | 40% | 30-50% |
| `edges * 0.3` | 最小保留比例 | 30% | 20-40% |

## 🔍 故障排查

### 问题1：仍有双线条

**检查**：
1. 查看控制台是否输出"检测到粗线条"
2. 如果没有，线条可能不够粗

**解决**：
```python
# 降低粗线条检测阈值
if cv2.countNonZero(binary) > cv2.countNonZero(edges) * 1.5:  # 从2改为1.5
```

### 问题2：线条断裂

**原因**：距离变换阈值太高

**解决**：
```python
# 降低中心线提取阈值
_, centerline = cv2.threshold(dist_transform, max_dist * 0.3, 255, cv2.THRESH_BINARY)  # 从0.4改为0.3
```

### 问题3：线条太多

**原因**：距离变换阈值太低

**解决**：
```python
# 提高中心线提取阈值
_, centerline = cv2.threshold(dist_transform, max_dist * 0.5, 255, cv2.THRESH_BINARY)  # 从0.4改为0.5
```
