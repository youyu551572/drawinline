# 区域选择器使用指南

## 简介

区域选择器是图片线条自动绘画工具的核心功能之一，提供可视化的方式让用户精确框选绘画区域。

## 快速开始

### 启动选择器

1. 在主界面找到"绘画区域"框架
2. 点击 **"📍 框选绘画区域"** 按钮
3. 屏幕会出现一个半透明的全屏窗口

### 框选区域

1. **移动鼠标**
   - 鼠标指针变为十字形
   - 移动到想要开始绘画的位置

2. **拖拽框选**
   - 按住鼠标左键
   - 拖动鼠标框选区域
   - 会出现红色矩形框实时显示

3. **查看信息**
   - 顶部显示操作提示
   - 左上角显示当前位置和尺寸
   - 实时更新尺寸信息

4. **确认选择**
   - 按 **Enter** 键（或小键盘Enter）确认
   - 按 **Esc** 键取消选择

### 查看结果

确认后，主界面会自动填充：
- **位置 X**：框选区域左上角的X坐标
- **位置 Y**：框选区域左上角的Y坐标
- **宽**：框选区域的宽度
- **高**：框选区域的高度

## 使用技巧

### 技巧 1：先准备好目标程序

**推荐流程**：
```
1. 打开目标绘画程序（如画图）
2. 创建或打开画布
3. 确定大致绘画位置
4. 返回本程序启动选择器
5. 框选精确区域
```

**优点**：
- 可以透过半透明窗口看到底层程序
- 更精确地定位绘画区域
- 避免选择错误

### 技巧 2：留出边距

**问题**：线条贴边可能被裁剪

**解决方案**：
- 框选时上下左右各留 10-20 像素边距
- 确保图片完整显示在区域内
- 避免线条超出边界

**示例**：
```
原始想法：框选整个画布
改进方法：框选画布内部区域，留出边框
```

### 技巧 3：考虑图片比例

**图片尺寸与框选尺寸**：

如果图片是 **800x600**，建议框选：
- 相同比例：800x600 区域
- 或按比例缩放：400x300、1600x1200等

**为什么**：
- 保持原始宽高比
- 避免图片变形
- 绘画效果更好

### 技巧 4：记录常用位置

**场景**：经常在同一程序的同一位置绘画

**方法**：
1. 第一次使用选择器精确框选
2. 记录显示的坐标和尺寸
3. 下次直接在输入框手动输入
4. 省去框选步骤

**示例记录**：
```
画图程序 - 默认画布：
X: 150, Y: 180
宽: 800, 高: 600

Photoshop - A4画布：
X: 300, Y: 150
宽: 1240, 高: 1754
```

### 技巧 5：多次尝试找最佳位置

**不用担心试错**：
- 按Esc可以随时取消
- 重新点击按钮再次选择
- 多试几次找到最佳位置

**建议**：
1. 第一次粗略框选
2. 开始绘画测试
3. 发现问题后重新精确框选
4. 直到满意为止

## 常见问题

### Q1: 为什么要用选择器而不是直接输入坐标？

**对比**：

**直接输入坐标**：
- ❌ 需要手动计算坐标
- ❌ 容易输入错误
- ❌ 无法直观看到位置
- ❌ 调整麻烦

**使用选择器**：
- ✅ 直观可视化
- ✅ 实时预览效果
- ✅ 精确到像素
- ✅ 所见即所得

### Q2: 选择器窗口看不清怎么办？

**原因**：窗口太透明

**解决方案**：
- 当前透明度设置为 50%（alpha=0.5）
- 已经足够看清底层窗口
- 如需调整，可修改 `area_selector.py` 中的 `alpha` 值

### Q3: 框选时误操作了怎么办？

**情况 1：框选位置不对**
- 按 Esc 取消
- 重新点击按钮再选

**情况 2：框选到一半想重来**
- 继续拖拽完成框选
- 按 Esc 取消
- 重新开始

**情况 3：尺寸太小或太大**
- 同样按 Esc 取消
- 重新精确框选

### Q4: Enter键不起作用？

**检查项**：
1. 确认已经完成框选（拖拽鼠标）
2. 确认选择器窗口获得了焦点
3. 尝试点击窗口任意位置重新获取焦点
4. 也可以使用小键盘的Enter键

**注意**：
- 必须先框选后才能确认
- 不能在没有框选的情况下按Enter

### Q5: 能否保存多个常用位置？

**当前版本**：
- 暂不支持保存预设位置
- 可以手动记录到笔记本中

**未来计划**：
- 添加位置预设功能
- 一键切换常用位置
- 保存为配置文件

### Q6: 选择器支持多显示器吗？

**支持情况**：
- 支持多显示器
- 但只会在主显示器上显示选择器
- 如需在副显示器绘画，需手动输入坐标

**建议**：
- 在主显示器上使用选择器
- 或将目标程序移到主显示器

## 技术细节

### 坐标系统

**屏幕坐标**：
```
(0,0) ──────────► X轴
  │
  │
  │
  ▼
 Y轴
```

- 左上角为 (0, 0)
- 向右X增大
- 向下Y增大

### 返回值

```python
result = select_drawing_area()

if result:
    x, y, width, height = result
    print(f"位置: ({x}, {y})")
    print(f"尺寸: {width} × {height}")
else:
    print("用户取消了选择")
```

### 最小尺寸限制

**限制**：
- 宽度和高度都必须 > 10 像素
- 太小的区域会被拒绝

**提示**：
- 如果区域太小，会显示错误提示
- 需要重新框选更大的区域

## 最佳实践

### ✅ 推荐做法

1. **先测试小图**
   - 用简单图片测试位置
   - 确认准确后再处理复杂图片

2. **保持窗口不动**
   - 选择器确认后不要移动目标窗口
   - 否则位置会偏移

3. **合理设置尺寸**
   - 根据图片实际尺寸设置
   - 避免过大或过小

4. **定期校准**
   - 如果经常使用
   - 定期重新选择确认位置

### ❌ 避免的错误

1. **不要在选择器打开时切换窗口**
   - 可能导致位置不准
   - 先确认再切换

2. **不要框选太小的区域**
   - 至少100x100像素
   - 太小无法容纳图片

3. **不要跨窗口选择**
   - 一次只选择一个窗口区域
   - 不要选择多个应用
