## 🐛 问题描述

### 问题1：绘画位置与预览位置不一致

**用户反馈**：
> "测试绘画位置还是与选择绘画位置时预览的位置不一致。"

**问题分析**：
1. 用户拖动鼠标框选绘画区域
2. 释放鼠标后，鼠标可能移动到其他位置
3. 按下回车键确认选择
4. `on_confirm()`方法使用当前鼠标位置计算框选区域
5. **导致确认的坐标与拖动时的坐标不一致**

**代码问题**：
```python
# 旧代码 - 在确认时重新计算鼠标位置
def on_confirm(self, event=None):
    # 获取当前鼠标位置（可能已经移动！）
    x = self.window.winfo_pointerx() - self.window.winfo_rootx()
    y = self.window.winfo_pointery() - self.window.winfo_rooty()
    
    # 计算区域（使用错误的鼠标位置）
    x1 = min(self.start_x, x)
    y1 = min(self.start_y, y)
    # ...
```

**后果**：
- 预览时显示的线条位置 ≠ 实际绘画的线条位置
- 用户体验差，无法准确绘画

## ✅ 解决方案

### 修复1：保存拖动时的坐标

**核心思路**：
在用户拖动鼠标时保存框选坐标，确认时直接使用保存的坐标。

**代码实现**：

#### 1. 添加变量保存坐标

```python
# area_selector.py - AreaSelectorV2.__init__
def __init__(self, strokes=None, image_size=None):
    # ... 其他初始化代码 ...
    
    # 保存当前框选的坐标（修复确认时坐标不一致问题）
    self.current_x1 = None
    self.current_y1 = None
    self.current_width = None
    self.current_height = None
```

#### 2. 拖动时保存坐标

```python
# area_selector.py - on_mouse_drag
def on_mouse_drag(self, event):
    if self.start_x is None:
        return

    # 计算区域
    x1 = min(self.start_x, event.x)
    y1 = min(self.start_y, event.y)
    x2 = max(self.start_x, event.x)
    y2 = max(self.start_y, event.y)
    width = x2 - x1
    height = y2 - y1
    
    # 💡 关键：保存当前框选的坐标
    self.current_x1 = x1
    self.current_y1 = y1
    self.current_width = width
    self.current_height = height
    
    # ... 绘制预览线条 ...
```

#### 3. 确认时使用保存的坐标

```python
# area_selector.py - on_confirm
def on_confirm(self, event=None):
    """确认选择"""
    # 💡 使用保存的框选坐标，而不是重新计算鼠标位置
    # 这样可以避免用户在确认时鼠标移动导致的坐标偏差
    if self.current_x1 is not None and self.current_width is not None:
        if self.current_width > 10 and self.current_height > 10:
            self.selected_area = (
                self.current_x1, 
                self.current_y1, 
                self.current_width, 
                self.current_height
            )
            print(f"确认框选区域: 位置({self.current_x1}, {self.current_y1}), 尺寸({self.current_width} × {self.current_height})")
            self.window.destroy()
    elif self.start_x is not None:
        # 如果没有拖动过，使用旧逻辑（兼容性）
        # ...
```

## 🔧 技术细节

### 坐标系统说明

```
┌────────────────────────────────────┐
│  透明选择窗口（全屏）              │
│                                    │
│  (start_x, start_y)                │
│      ┌──────────────────┐          │
│      │                  │          │
│      │   框选区域       │          │
│      │                  │          │
│      └──────────────────┘          │
│                   (event.x, event.y)│
│                                    │
└────────────────────────────────────┘

计算方式：
x1 = min(start_x, event.x)
y1 = min(start_y, event.y)
width = max(start_x, event.x) - x1
height = max(start_y, event.y) - y1
```

### 坐标保存时机

```python
# on_mouse_drag 中每次拖动都更新
self.current_x1 = x1
self.current_y1 = y1
self.current_width = width
self.current_height = height

# on_confirm 中直接使用
if self.current_x1 is not None:
    self.selected_area = (
        self.current_x1,      # 左上角X
        self.current_y1,      # 左上角Y
        self.current_width,   # 宽度
        self.current_height   # 高度
    )
```

## 💡 经验教训

### 问题根源

**窗口事件处理的时序问题**：
- 用户的拖动操作和确认操作是分离的
- 在两个操作之间，鼠标位置可能改变
- 不应该在确认时重新计算鼠标位置

**正确做法**：
1. 在状态变化时立即保存关键数据
2. 在需要时直接使用保存的数据
3. 避免依赖可能变化的外部状态（如鼠标位置）

---

### UI设计原则

**信息展示优化**：
- 相关信息应该紧凑展示
- 避免占用过多空间
- 使用合适的分隔符增强可读性
