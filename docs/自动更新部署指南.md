# 自动更新部署指南

## 📋 概述

本文档详细介绍如何为YouYu自动绘画软件部署免费的自动更新系统。

---

## 🚀 方案选择

### **推荐方案：GitHub Releases + 自定义更新检测**

✅ **优点**：
- 完全免费
- 无需服务器
- 可靠稳定
- 支持多平台
- 版本管理清晰

❌ **局限**：
- 需要GitHub账号
- 国内访问可能较慢（可配置镜像）
- 需要手动发布Release

---

## 💻 实现步骤

### **Step 1: 准备GitHub仓库**

#### 1.1 创建GitHub仓库
```bash
# 如果还没有仓库
1. 访问 https://github.com/new
2. 创建新仓库，例如: drawinline
3. 上传代码到仓库
```

#### 1.2 配置仓库信息
在 `modern_app.py` 中修改配置：
```python
# 找到 _check_for_updates 方法
REPO_OWNER = "your-username"  # 改为你的GitHub用户名
REPO_NAME = "drawinline"      # 改为你的仓库名
```

---

### **Step 2: 发布新版本**

#### 2.1 准备发布文件
```bash
# 打包你的软件（例如使用PyInstaller）
pyinstaller --onefile --windowed --icon=icon.ico modern_main.py

# 生成的文件在 dist/ 目录
dist/modern_main.exe
```

#### 2.2 创建GitHub Release

**方式一：通过GitHub网页**
1. 访问仓库页面
2. 点击右侧 "Releases" → "Create a new release"
3. 填写信息：
   - **Tag version**: `v2.0.33` （版本号格式：v + 主版本.次版本.修订号）
   - **Release title**: `v2.0.33 - 功能描述`
   - **Description**: 
     ```markdown
     ## ✨ 新增功能
     - 添加自动更新检测
     - 优化截图识别
     
     ## 🐛 Bug修复
     - 修复了XXX问题
     
     ## 📝 注意事项
     - 需要Python 3.8+
     ```
   - **Attach binaries**: 上传 `modern_main.exe`

4. 点击 "Publish release"

**方式二：使用GitHub CLI**
```bash
# 安装GitHub CLI
# Windows: scoop install gh
# macOS: brew install gh

# 登录
gh auth login

# 创建Release
gh release create v2.0.33 \
  --title "v2.0.33 - 添加自动更新" \
  --notes "详细更新说明..." \
  dist/modern_main.exe
```

### **Step 3: 版本号管理**

#### 3.1 语义化版本控制
遵循 [Semantic Versioning](https://semver.org/)：

```
主版本.次版本.修订号
MAJOR.MINOR.PATCH

v2.0.32
 │ │  │
 │ │  └─ 修订号：bug修复
 │ └──── 次版本号：新功能（向下兼容）
 └────── 主版本号：重大更新（不兼容旧版本）
```

#### 3.2 更新版本号
每次发布前，更新以下位置的版本号：

1. **modern_app.py**
```python
# 版本号显示
version_label = QLabel("v2.0.33")  # 更新这里

# _check_for_updates 方法
CURRENT_VERSION = "2.0.33"  # 更新这里
```

2. **CHANGELOG.md**
```markdown
## [2.0.33] - 2024-11-24
### ✨ 新增功能
...
```

3. **docs/项目概览.md**
```markdown
**v2.0.33（最新PyQt5版）- 2024-11-24**
...
```

### **Step 4: 测试更新功能**

#### 4.1 本地测试
```python
# 创建测试脚本 test_updater.py
from auto_updater import AutoUpdater

updater = AutoUpdater(
    repo_owner="your-username",
    repo_name="drawinline",
    current_version="2.0.32"  # 使用旧版本号测试
)

update_info = updater.check_for_updates()
if update_info:
    print(f"✅ 发现新版本: {update_info['version']}")
    print(f"下载地址: {update_info['download_url']}")
else:
    print("❌ 没有发现更新")
```

#### 4.2 完整测试流程
1. 发布一个新版本（例如v2.0.33）
2. 运行旧版本软件（v2.0.32）
3. 等待启动后500ms，应该弹出更新提醒
4. 点击"立即更新"，浏览器打开下载页面
5. 下载并安装新版本

## 🔧 高级配置

### **1. 禁用自动检查更新**

用户可以通过配置文件禁用：
```json
// update_config.json
{
  "auto_check": false
}
```

程序中设置：
```python
from auto_updater import UpdateConfig

# 禁用自动检查
UpdateConfig.set_auto_check(False)

# 启用自动检查
UpdateConfig.set_auto_check(True)
```

### **2. 跳过特定版本**

用户点击"跳过此版本"后：
```json
// update_config.json
{
  "auto_check": true,
  "skip_version": "2.0.33"
}
```

### **3. 自定义检查频率**

修改 `modern_app.py`：
```python
# 在 _delayed_init 方法中
QTimer.singleShot(500, self._check_for_updates)  # 启动时检查

# 添加定期检查（例如每天一次）
self.update_timer = QTimer()
self.update_timer.timeout.connect(self._check_for_updates)
self.update_timer.start(24 * 60 * 60 * 1000)  # 24小时
```

### **4. 配置国内镜像**

对于国内用户，可以使用GitHub镜像：
```python
# auto_updater.py 中修改
self.api_url = f"https://api.github.com/repos/{repo_owner}/{repo_name}/releases/latest"

# 改为
# self.api_url = f"https://ghproxy.com/https://api.github.com/repos/{repo_owner}/{repo_name}/releases/latest"
```

### **1. 更新对话框**

当前实现的对话框包含：
- ✅ 新版本号显示
- ✅ 当前版本号显示

- 失败不影响软件运行

### **3. 智能提醒**

- 每个版本只提醒一次
- 用户可选择跳过
- 支持完全禁用自动检查

## 🔒 安全考虑

### **1. HTTPS连接**
```python
# 始终使用HTTPS
self.api_url = "https://api.github.com/..."  # ✅
# 而不是
# self.api_url = "http://..."  # ❌
```

### **2. 验证下载**

建议添加SHA256校验：
```python
# 在Release中添加校验文件
modern_main.exe
modern_main.exe.sha256

# 下载后验证
import hashlib

def verify_file(file_path, expected_hash):
    sha256 = hashlib.sha256()
    with open(file_path, 'rb') as f:
        for block in iter(lambda: f.read(4096), b''):
            sha256.update(block)
    return sha256.hexdigest() == expected_hash
```

### **3. 避免自动安装**

出于安全考虑，当前实现只打开下载页面，让用户手动下载安装。

## 🐛 常见问题

### **Q: GitHub API限流怎么办？**
A: 未认证的请求限制为60次/小时。解决方法：
```python
# 使用Personal Access Token
headers = {
    'Authorization': f'token {YOUR_GITHUB_TOKEN}'
}
response = requests.get(url, headers=headers)
# 限制提升到5000次/小时
```

### **Q: 国内用户无法访问GitHub？**
A: 使用镜像或CDN：
- https://ghproxy.com/
- https://gh.api.99988866.xyz/
- https://mirror.ghproxy.com/

### **Q: 如何实现自动下载安装？**
A: 需要更复杂的实现：
```python
# 1. 下载文件
import urllib.request
urllib.request.urlretrieve(download_url, 'update.exe')

# 2. 启动安装程序
import subprocess
subprocess.Popen(['update.exe'])

# 3. 退出当前程序
sys.exit(0)
```

### **Q: 支持增量更新吗？**
A: 当前实现不支持。增量更新需要：
- 差分算法（bsdiff）
- 补丁生成和应用
- 更复杂的更新逻辑
