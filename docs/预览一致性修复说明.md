# 预览一致性修复说明

## 🎯 用户需求

**核心要求**：
> "画布上显示什么样，画出来就什么样"

**发现的问题**：
1. 画布预览的线条与选择绘画位置时预览的线条不一样
2. 绘画速度比预期慢

---

## 🔍 问题诊断

### 问题1：预览不一致

**根本原因**：
- PreviewCanvas采样了线条点（>100点时采样到50点）
- area_selector不采样，显示所有点
- 导致两个预览看起来不一样

**代码对比**：

```python
# PreviewCanvas（之前 - 有采样）
scaled_points = [(int(round(x * scale)), int(round(y * scale))) for x, y in stroke]

if len(scaled_points) > 100:  # ❌ 采样
    step = max(2, len(scaled_points) // 50)
    scaled_points = scaled_points[::step]

for i in range(len(scaled_points) - 1):
    painter.drawLine(...)

# area_selector（一直是完整的）
for i in range(0, len(stroke), point_step):  # ✅ 不采样或少量采样
    x_point, y_point = stroke[i]
    new_x = x1 + round(x_point * scale_x)
    new_y = y1 + round(y_point * scale_y)
    stroke_coords.extend([new_x, new_y])
```

---

## ✅ 修复方案

### 修复1：PreviewCanvas不采样

**修复后代码**：
```python
# PreviewCanvas（现在 - 不采样）
for idx, stroke in enumerate(self.strokes):
    if len(stroke) < 2:
        continue
    
    # 不做任何采样，直接缩放所有点（与area_selector和实际绘画完全一致）✅
    for i in range(len(stroke) - 1):
        x1, y1 = stroke[i]
        x2, y2 = stroke[i + 1]
        
        # 使用round进行缩放（与area_selector和实际绘画完全一致）✅
        x1_scaled = int(round(x1 * scale))
        y1_scaled = int(round(y1 * scale))
        x2_scaled = int(round(x2 * scale))
        y2_scaled = int(round(y2 * scale))
        
        painter.drawLine(x1_scaled, y1_scaled, x2_scaled, y2_scaled)
```

**优势**：
- ✅ 与area_selector预览完全一致
- ✅ 与实际绘画完全一致
- ✅ 所见即所得

## 📊 一致性保证

### 完整数据流

```
imgprocess.py 识别线条
    ↓
self.strokes（原始坐标）
    ↓
┌──────────────┬──────────────┬──────────────┐
│              │              │              │
PreviewCanvas  area_selector  DrawingThread
│              │              │              │
画布预览        框选预览        实际绘画
│              │              │              │
└──────────────┴──────────────┴──────────────┘
         使用相同的缩放逻辑
      int(round(x * scale)) ✅
```

### 三个位置的缩放逻辑

1. **PreviewCanvas（画布预览）**：
```python
x_scaled = int(round(x * scale))
y_scaled = int(round(y * scale))
```

2. **area_selector（框选预览）**：
```python
new_x = x1 + round(x_point * scale_x)
new_y = y1 + round(y_point * scale_y)
```

3. **DrawingThread（实际绘画）**：
```python
scaled_stroke = [(offset_x + int(round(x * scale_x)), 
                  offset_y + int(round(y * scale_y))) 
                 for x, y in stroke]
```

**共同点**：
- ✅ 都使用 `round()` 四舍五入
- ✅ 都使用 `int()` 转整数
- ✅ 都不采样或采样一致
- ✅ 保证了完全的一致性
