# 使用示例

本文档提供详细的使用示例，帮助你快速上手图片线条自动绘画工具。

## 示例 1：绘制简单图形

### 场景描述
绘制一个简单的笑脸表情图案到Windows画图程序中。

### 准备工作

1. **准备图片**
   - 找一张简单的笑脸简笔画
   - 或者手绘一个笑脸并拍照/扫描
   - 确保图片背景干净，线条清晰

2. **打开画图程序**
   ```
   Windows + R → 输入 mspaint → 回车
   ```

3. **准备画布**
   - 调整画布大小（建议 800x600）
   - 选择"画笔"工具
   - 选择黑色
   - 画笔粗细设置为 3-5 像素

### 操作步骤

#### 步骤 1：启动程序

双击 `start.bat` 或在命令行运行：
```bash
python main.py
```

#### 步骤 2：加载图片

1. 点击"选择图片"按钮
2. 选择准备好的笑脸图片
3. 确认加载成功（路径显示在输入框中）

#### 步骤 3：处理图片

**推荐参数（简单图形）**：
- 模糊核大小：3
- 边缘检测阈值1：40
- 边缘检测阈值2：120
- 最小线条长度：30
- 简化线条：✓ 勾选
- 简化程度：2.0

点击"处理图片"按钮，查看预览效果。

**预期结果**：
- 右侧画布显示识别的线条
- 信息显示：检测到 3-5 条线条（圆脸、两个眼睛、嘴巴）
- 共约 50-150 个绘画点

#### 步骤 4：设置绘画位置

**方法 A：自动捕获**
1. 点击"选择位置"按钮
2. 快速切换到画图程序
3. 将鼠标移到画布左上角
4. 等待 5 秒
5. 切回程序确认坐标

**方法 B：手动输入**
1. 在画图程序中，鼠标移到画布左上角
2. 使用 Windows 截图工具查看坐标
3. 在程序中输入坐标（例如：X=100, Y=150）

#### 步骤 5：调整绘画参数

**推荐参数**：
- 绘画速度：0.005（标准）
- 倒计时：3 秒

#### 步骤 6：开始绘画

1. 确保画图程序已激活
2. 确保画笔工具已选择
3. 点击"开始绘画"按钮
4. 阅读确认对话框
5. 点击"是"
6. 程序窗口最小化
7. 倒计时 3 秒
8. 开始自动绘画

#### 步骤 7：观察结果

- 进度条显示完成进度
- 画图程序中出现笑脸图案
- 完成后程序窗口恢复

### 预期效果

✓ 笑脸轮廓清晰  
✓ 线条连续流畅  
✓ 位置准确  
✓ 绘画时间约 10-30 秒

### 可能问题

**问题 1：线条太多或太少**
- 调整"边缘检测阈值1"
- 太多 → 增大到 60
- 太少 → 减小到 30

**问题 2：位置偏移**
- 重新选择位置
- 确保画图窗口没有移动

**问题 3：线条不连续**
- 降低"绘画速度"到 0.008
- 检查画图程序是否响应慢

## 示例 2：复制 Logo 图案

### 场景描述
将公司 Logo 或品牌图标绘制到设计软件中。

### 准备工作

1. **准备 Logo 图片**
   - 高分辨率 PNG 格式
   - 背景透明或纯白
   - 线条清晰、对比度高

2. **打开设计软件**
   - Paint.NET（免费）
   - Photoshop
   - Krita

3. **准备图层**
   - 创建新图层用于绘画
   - 选择合适的画笔
   - 设置画笔颜色和粗细

### 操作步骤

#### 推荐参数（Logo 图案）

**图像处理**：
- 模糊核大小：5
- 边缘检测阈值1：50
- 边缘检测阈值2：150
- 最小线条长度：50
- 简化线条：✓
- 简化程度：1.5

**绘画设置**：
- 绘画速度：0.006
- 倒计时：5 秒

#### 特别注意

1. **颜色处理**
   - 如果 Logo 有多种颜色，需要分别处理
   - 先绘制主色调线条
   - 再手动切换颜色绘制其他部分

2. **精度要求**
   - Logo 通常要求较高精度
   - 简化程度不要太大
   - 速度适当放慢

3. **多次迭代**
   - 第一次可能不完美
   - 调整参数重新处理
   - 找到最佳参数组合

### 实用技巧

**技巧 1：分层绘制**
```
1. 先绘制外轮廓
2. 再绘制内部细节
3. 最后绘制文字部分
```

**技巧 2：测试定位**
```
1. 先用小图测试位置是否准确
2. 确认后再处理完整 Logo
3. 避免浪费时间
```

**技巧 3：保存参数**
```
记录最佳参数组合：
- 模糊核：5
- 阈值：50/150
- 最小长度：50
- 简化：1.5
- 速度：0.006

下次直接应用
```

## 示例 3：素描作品转绘

### 场景描述
将手绘素描作品数字化，转绘到数字绘画软件中。

### 准备工作

1. **素描图片**
   - 用手机或扫描仪获取高质量图片
   - 调整对比度和亮度
   - 去除背景杂色

2. **图片预处理（推荐）**
   - 使用 GIMP 或 Photoshop
   - 转换为黑白图像
   - 增强线条对比度
   - 去除噪点

3. **绘画软件**
   - Krita（推荐，免费且专业）
   - Clip Studio Paint
   - Photoshop

### 操作步骤

#### 推荐参数（素描作品）

**图像处理**：
- 模糊核大小：5-7
- 边缘检测阈值1：30-40
- 边缘检测阈值2：90-120
- 最小线条长度：30
- 简化线条：✓
- 简化程度：1.5-2.0

**绘画设置**：
- 绘画速度：0.008（慢速，确保质量）
- 倒计时：5 秒

### 高级技巧

#### 技巧 1：多层次处理

**第一遍：主线条**
```
参数设置：
- 阈值较高（50/150）
- 最小长度较大（80）
- 只捕获主要轮廓

绘制到底层
```

**第二遍：细节线条**
```
参数设置：
- 阈值较低（30/90）
- 最小长度较小（30）
- 捕获细节

绘制到新图层
```

#### 技巧 2：区域分割

对于复杂素描：
1. 使用图片编辑软件裁剪
2. 分成多个区域
3. 分别处理和绘制
4. 在目标软件中拼接

#### 技巧 3：手工修正

1. 自动绘制主体部分
2. 手工修正细节
3. 添加阴影和纹理
4. 最终调整

### 质量检查清单

- [ ] 主要轮廓清晰
- [ ] 线条连续流畅
- [ ] 细节保留完整
- [ ] 比例准确
- [ ] 无明显断线
- [ ] 位置对齐正确

## 批量处理示例

### 场景：处理多张相似图片

#### 脚本化处理

创建配置文件 `config.json`：
```json
{
  "blur_kernel": 5,
  "threshold1": 50,
  "threshold2": 150,
  "min_length": 50,
  "simplify": true,
  "epsilon": 2.0
}
```

#### 批处理流程

1. **准备图片列表**
   - 将所有图片放在同一文件夹
   - 命名规则统一（如 img001.png, img002.png）

2. **记录参数**
   - 处理第一张找到最佳参数
   - 保存参数配置

3. **批量应用**
   - 对每张图片应用相同参数
   - 自动保存预览结果
   - 生成绘画指令列表

4. **依次绘制**
   - 按顺序处理每张图片
   - 在不同位置绘制
   - 或绘制到不同文件

## 故障排查示例

### 案例 1：绘画偏移

**问题描述**：
绘画结果相对目标位置有偏移

**排查步骤**：
1. 检查屏幕缩放设置
   - Windows 设置 → 显示 → 缩放
   - 确保设置为 100%

2. 重新捕获位置
   - 使用"选择位置"功能
   - 确保精确对准

3. 验证坐标
   - 使用测试小图验证
   - 微调 X、Y 坐标

**解决方案**：
```
正确的位置 = 观察到的位置 + 偏移量
如果向右偏移 20 像素：X 坐标减 20
如果向下偏移 10 像素：Y 坐标减 10
```

### 案例 2：线条识别过多

**问题描述**：
识别出大量噪点和无用线条

**排查步骤**：
1. 查看原图质量
2. 检查是否有背景纹理
3. 观察预览中的噪点分布

**解决方案**：
```
方法 1：提高阈值
- 阈值1：50 → 70
- 阈值2：150 → 210

方法 2：增加最小长度
- 最小长度：50 → 100

方法 3：增大模糊
- 模糊核：5 → 7

方法 4：预处理图片
- 使用图片编辑软件去噪
```

### 案例 3：绘画速度太慢

**问题描述**：
绘制一张图需要很长时间

**排查步骤**：
1. 检查点数统计
2. 观察是否有过多细节线条

**解决方案**：
```
优化 1：增大简化程度
- epsilon：2.0 → 4.0
- 点数可减少 50%+

优化 2：过滤短线条
- 最小长度：50 → 100

优化 3：提高速度
- 速度：0.005 → 0.003
- 但可能影响质量

优化 4：预处理简化
- 降低图片分辨率
- 先缩小 50%
```
