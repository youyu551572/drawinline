# 自动更新功能 - 快速开始

## 🚀 5分钟配置自动更新

### 1️⃣ **安装依赖**
```bash
pip install requests packaging
```

### 2️⃣ **配置仓库信息**

编辑 `modern_app.py`，找到 `_check_for_updates` 方法：
```python
def _check_for_updates(self):
    """检查更新（后台异步）"""
    try:
        # 修改这里！
        REPO_OWNER = "your-username"  # 改为你的GitHub用户名
        REPO_NAME = "drawinline"      # 改为你的仓库名
        CURRENT_VERSION = "2.0.32"    # 当前版本号
```

**示例**：
```python
REPO_OWNER = "zhangsan"      # 你的GitHub用户名
REPO_NAME = "my-drawinline"  # 你的仓库名
CURRENT_VERSION = "2.0.32"
```

### 3️⃣ **发布新版本到GitHub**

#### 方式一：网页操作（推荐新手）

1. 访问你的GitHub仓库
2. 点击右侧 **"Releases"** → **"Create a new release"**
3. 填写信息：
   ```
   Tag version: v2.0.33
   Release title: v2.0.33 - 添加自动更新
   Description: 
   ## ✨ 新增功能
   - 自动检测更新
   - 一键下载安装
   ```
4. 上传打包好的 `.exe` 文件
5. 点击 **"Publish release"**

#### 方式二：命令行（推荐熟手）

```bash
# 安装GitHub CLI
# Windows: scoop install gh

# 登录
gh auth login

# 创建Release并上传文件
gh release create v2.0.33 \
  --title "v2.0.33 - 添加自动更新" \
  --notes "新增自动更新功能" \
  dist/modern_main.exe
```

### 4️⃣ **测试**

1. 运行旧版本软件（v2.0.32）
2. 启动后约0.5秒，会弹出更新提醒
3. 点击"立即更新"，浏览器打开下载页面
4. 下载并测试新版本

## 🎯 **版本号规则**

遵循语义化版本（Semantic Versioning）：

```
v2.0.32
 │ │  │
 │ │  └─ 修订号：bug修复（+1）
 │ └──── 次版本号：新功能，向下兼容（+1）
 └────── 主版本号：重大更新，不兼容（+1）
```

**示例**：
- `v2.0.32` → `v2.0.33`：修复bug
- `v2.0.33` → `v2.1.0`：新增功能
- `v2.1.0` → `v3.0.0`：重大更新

## 🔧 **配置文件**

软件会在根目录生成 `update_config.json`：

```json
{
  "auto_check": true,           // 是否自动检查更新
  "skip_version": "2.0.33"      // 跳过的版本号
}
```

**禁用自动检查**：
```python
from auto_updater import UpdateConfig
UpdateConfig.set_auto_check(False)
```

## ❓ **常见问题**

### **Q: 为什么检测不到更新？**
A: 检查以下几点：
1. `REPO_OWNER` 和 `REPO_NAME` 是否正确
2. GitHub仓库是否公开
3. 是否发布了新的Release
4. 网络连接是否正常

### **Q: 如何测试更新功能？**
A: 
```python
# 临时降低版本号测试
CURRENT_VERSION = "1.0.0"  # 改为很旧的版本
```

### **Q: 能否自动下载安装？**
A: 当前版本不支持。出于安全考虑，只打开下载页面。

### **Q: 国内访问GitHub慢怎么办？**
A: 修改 `auto_updater.py`，使用镜像：
```python
self.api_url = "https://ghproxy.com/" + self.api_url
```
