| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **小键盘-键** | 停止绘画 | 在绘画过程中按下，立即停止 |

## 📋 使用说明

### 小键盘-键 - 停止绘画

**使用场景**：
- 绘画过程中发现位置不对
- 需要紧急停止
- 想要重新开始

**操作方式**：
1. 在绘画过程中
2. 按下**小键盘-键**
3. 绘画立即停止
4. 主窗口恢复显示
5. 状态栏显示“快捷键：小键盘-键停止绘画”

**等效于**：点击“⏹️ 停止”按钮

---

### 小键盘+键 - 开始绘画

**使用场景**：
- 已经处理好图片
- 已经框选好绘画区域
- 想要快速开始绘画

**操作方式**：
1. 确保已处理图片
2. 确保已框选绘画区域
3. 按下**小键盘+键**
4. 显示确认对话框
5. 点击“是”开始绘画
6. 状态栏显示“快捷键：小键盘+键开始绘画”

**等效于**：点击“▶️ 开始”按钮

**限制条件**：
- ✅ 必须已处理图片
- ✅ 必须已框选绘画区域
- ❌ 正在绘画时不能使用

## 💡 实现原理

### 技术实现

**1. 启用键盘事件**：
```python
# 在__init__中
self.setFocusPolicy(Qt.StrongFocus)  # 启用键盘焦点
```

**2. 重写键盘事件处理**：
```python
def keyPressEvent(self, event: QKeyEvent):
    """键盘事件处理"""
    # 小键盘-键：停止绘画
    if event.key() == Qt.Key_Minus:
        if self.drawing_thread and self.drawing_thread.isRunning():
            self.stop_drawing()
            self.update_status("快捷键：小键盘-键停止绘画", "info")
    
    # 小键盘+键：开始绘画
    elif event.key() == Qt.Key_Plus:
        if self.strokes and not (self.drawing_thread and self.drawing_thread.isRunning()):
            if self.draw_width > 0 and self.draw_height > 0:
                self.start_drawing()
                self.update_status("快捷键：小键盘+键开始绘画", "info")
            else:
                self.update_status("请先框选绘画区域！", "error")
    
    # 调用父类的keyPressEvent
    super().keyPressEvent(event)
```

### 状态检查

**小键盘-键停止**：
- ✅ 检查绘画线程是否存在
- ✅ 检查绘画线程是否正在运行
- ✅ 只在绘画时响应

**小键盘+键开始**：
- ✅ 检查是否有识别的线条
- ✅ 检查是否正在绘画（避免重复）
- ✅ 检查是否已框选区域
- ✅ 所有条件满足才执行

### main.py的键盘功能

```python
from pynput import keyboard

def _on_key_press(self, key):
    """键盘按键回调"""
    if key == keyboard.Key.space:
        self.space_pressed = True  # 暂停/继续
```

**功能**：
- 空格键：暂停/继续绘画

### modern_app.py的键盘功能（v2.0.14）

**使用PyQt5内置**：
```python
def keyPressEvent(self, event: QKeyEvent):
    if event.key() == Qt.Key_Minus:
        self.stop_drawing()  # 停止绘画
    elif event.key() == Qt.Key_Plus:
        self.start_drawing()  # 开始绘画
```

**功能**：
- 小键盘-键：停止绘画
- 小键盘+键：开始绘画

**优势**：
- ✅ 不需要额外的pynput库
- ✅ 使用PyQt5原生事件系统
- ✅ 更稳定、更轻量
- ✅ 更多快捷键支持

## 💡 用户提示

**使用技巧**：
1. 小键盘-键停止比鼠标点击更快
2. 小键盘+键开始可以节省鼠标操作
3. 确保主窗口有焦点（点击窗口）
4. 快捷键提示一直可见

**注意事项**：
- 窗口必须有焦点才能响应键盘
- 输入框有焦点时快捷键可能不响应
- 对话框打开时快捷键暂时失效
