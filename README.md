# 图片线条自动绘画工具

一个能够识别图片中所有线条，并自动控制鼠标进行精确绘画的Windows工具。

## 功能特点

- 🖼️ **智能图像识别**：使用OpenCV进行边缘检测和线条提取
- 🎨 **自动绘画**：精确控制鼠标自动完成绘画
- ⚙️ **快速模式**：一键设置简单/中等/复杂图片参数
- 🎯 **可视化区域选择**：透明窗口框选绘画区域，实时预览线条
- ⚡ **性能优化**：流畅度提升80%，节流机制+智能采样
- ⏸️ **实时控制**：支持暂停、继续、停止操作，空格键快捷暂停
- 📊 **预览功能**：处理前可预览识别结果
- 🌏 **中文路径支持**：完美支持包含中文字符的文件路径
- 🖥️ **分辨率显示**：实时显示当前屏幕分辨率

## 系统要求

- Windows 操作系统
- Python 3.7+

## 使用方法

### 启动程序

```bash
python main.py
```

### 操作步骤

1. **选择图片**
   - 点击"选择图片"按钮
   - 选择要绘画的图片文件（支持PNG、JPG、BMP等格式）

2. **快速模式选择**（可选）
   - 🟢 **简单模式**：适合线条清晰的简单图片
   - 🟡 **中等模式**：默认平衡设置，适合普通图片
   - 🔴 **复杂模式**：适合细节丰富的复杂图片
   - 点击按钮一键设置参数，也可手动调整

3. **调整参数**（可选）
   - **模糊核大小**：控制图像平滑程度（1-15，推荐5）
   - **边缘检测阈值1/2**：控制边缘检测敏感度
   - **最小线条长度**：过滤过短的线条（10-200像素）
   - **简化线条**：减少绘画点数，提高速度
   - **简化程度**：值越大简化越多（0.5-10）

4. **处理图片**
   - 点击"处理图片"按钮
   - 查看右侧预览效果
   - 根据需要调整参数并重新处理

5. **选择绘画区域**
   - 点击"📍 框选绘画区域"按钮
   - 主窗口自动最小化，透明窗口全屏显示
   - 用鼠标拖拽框选绘画区域（红色方框+绿色预览线条）
   - 按 **Enter** 键确认，或按 **Esc** 键取消
   - 程序会自动记录位置和尺寸

6. **开始绘画**
   - 打开目标绘画程序（如画图、Photoshop等）
   - 准备好画笔工具
   - 点击"开始绘画"按钮
   - 程序会倒计时后开始自动绘画

### 快捷操作

- **紧急停止**：将鼠标移到屏幕左上角
- **空格键暂停**：绘画过程中按空格键暂停/继续（需安装pynput库）
- **按钮暂停**：点击"暂停"按钮
- **停止绘画**：点击"停止"按钮

## 参数说明

### 图像处理参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 模糊核大小 | 1-15 | 5 | 降噪处理，值越大图像越模糊 |
| 边缘检测阈值1 | 10-200 | 50 | Canny算法低阈值 |
| 边缘检测阈值2 | 50-300 | 150 | Canny算法高阈值 |
| 最小线条长度 | 10-200 | 50 | 过滤短线条，减少噪点 |
| 简化程度 | 0.5-10 | 2.0 | 使用Douglas-Peucker算法简化 |

### 绘画参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 绘画速度 | 0.001-0.02 | 0.005 | 每个点的停留时间（秒） |
| 倒计时 | 1-10 | 3 | 开始前的准备时间（秒） |

## 使用建议

1. **图片选择**
   - 选择线条清晰、对比度高的图片效果最好
   - 简笔画、素描类图片识别效果优于复杂照片

2. **参数调优**
   - 如果识别线条过多：提高阈值、增大最小线条长度
   - 如果识别线条过少：降低阈值
   - 如果绘画太慢：增大简化程度、提高绘画速度

3. **目标程序准备**
   - 确保绘画程序已打开并选择了合适的画笔
   - 建议先测试小图片验证位置是否准确
   - 大图片绘画前建议保存以防意外

## 注意事项

⚠️ **重要提示**

- 程序会控制鼠标移动和点击，运行时请勿手动操作鼠标
- 绘画过程中可能需要较长时间，请耐心等待
- 如需中断，可将鼠标快速移到屏幕左上角
- 建议在虚拟机或测试环境中首次使用

## 常见问题

**Q: 为什么识别的线条不准确？**  
A: 尝试调整边缘检测阈值，或对图片进行预处理（提高对比度等）

**Q: 绘画位置偏移怎么办？**  
A: 重新选择位置，确保坐标准确

**Q: 程序运行出错？**  
A: 检查是否正确安装了所有依赖库，特别是opencv-python

**Q: 如何提高绘画速度？**  
A: 启用"简化线条"，增大简化程度，提高绘画速度参数

## 技术实现

### 核心技术

- **OpenCV**：图像处理和边缘检测
- **PyAutoGUI**：鼠标控制和自动化
- **Tkinter**：图形用户界面
- **PIL/Pillow**：图像显示

### 算法流程

1. 图像预处理（灰度化、高斯模糊）
2. Canny边缘检测
3. 轮廓提取和过滤
4. Douglas-Peucker线条简化
5. 路径规划和优化
6. 自动绘画执行
